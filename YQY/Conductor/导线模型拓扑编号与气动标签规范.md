# 导线模型拓扑、编号与气动标签规范

## 1. 适用范围

本文定义 YQY 当前单档多分裂导线模型的节点拓扑、连接顺序、统一编号、单元用途和气动参数绑定规则。

当前支持 1、2、4、6、8 分裂。多分裂耐张端部参考 THOP 的分组汇集方式实现；输入的两个坐标表示左右耐张挂点，不要求成为节点 1、2。

## 2. 子导线截面顺序

子导线按局部截面多边形排序，`wireId` 从 0 开始。四分裂的 `wireId=0` 位于局部右下角，之后沿多边形依次编号。

耐张端部按 `wireId` 分组：

- 二分裂：`{0,1}` 为一组；
- 四分裂：`{0,1}`、`{2,3}`；
- 六分裂：`{0,1,2}`、`{3,4,5}`；
- 八分裂：`{0,1,2,3}`、`{4,5,6,7}`。

同一组内的子导线共享左右分组节点，但各自拥有独立的导线单元。

## 3. 耐张端部连接

每一侧包含：

1. 一个输入坐标对应的耐张挂点；
2. 一个或两个分组节点；
3. 挂点到各分组节点的联板单元；
4. 两个分组节点之间的横向稳定梁（只有两组时创建）。

端部连接如下：

```text
                           子导线0
                    ┌────────────────
左挂点 ─ 左组节点1 ─┤
   │                └────────────────
   │                       子导线1
   │
   ├──── 横向稳定梁
   │
   │                       子导线2
   │                ┌────────────────
   └── 左组节点2 ───┤
                    └────────────────
                           子导线3
```

分组节点到每根子导线首个独立节点，以及末个独立节点到右分组节点的单元，均属于导线，不属于耐张硬件。

## 4. 节点统一编号

模型几何、耐张端部和间隔棒全部创建完成后统一重新编号，不依赖对象创建顺序。

每个分组的编号顺序为：

1. 左分组节点；
2. 组内各子导线的独立线身节点，按 `wireId`、左到右排列；
3. 右分组节点。

所有分组完成后依次编号：

1. 左耐张挂点；
2. 右耐张挂点；
3. 相内间隔棒中心节点；
4. 相间间隔棒新增节点；
5. 其他未分类节点。

四分裂、每根三个位于分组节点之间的独立节点示例：

```text
第一组
左组节点       1
子导线0        2,3,4
子导线1        5,6,7
右组节点       8

第二组
左组节点       9
子导线2        10,11,12
子导线3        13,14,15
右组节点       16

耐张挂点       17,18
附件新增节点   19...
```

逻辑节点链为：

```text
wire 0: 1 -> 2 -> 3 -> 4 -> 8
wire 1: 1 -> 5 -> 6 -> 7 -> 8
wire 2: 9 -> 10 -> 11 -> 12 -> 16
wire 3: 9 -> 13 -> 14 -> 15 -> 16
```

共享分组节点只有一个全局 ID，不创建重合的重复节点。

## 5. 单元统一编号

单元在模型生成完成后按以下顺序重新编号：

1. 各子导线的全部导线单元，按 `wireId`、左到右排列；
2. 左侧耐张联板；
3. 左侧稳定梁；
4. 右侧耐张联板；
5. 右侧稳定梁；
6. 相内间隔棒；
7. 相间间隔棒；
8. 其他未分类单元。

端部过渡单元包含在对应子导线的连续单元序列中。

## 6. 单元用途

```cpp
enum class ElementRole
{
    Generic = 0,
    Conductor,
    TensionHardware,
    IntraPhaseSpacer,
    InterPhaseSpacer
};
```

- `Conductor`：整根子导线，包括左右端部过渡单元；
- `TensionHardware`：耐张联板和横向稳定梁；
- `IntraPhaseSpacer`：相内间隔棒的外框和中心辐射杆；
- `InterPhaseSpacer`：相间间隔棒及其附属单元；
- `Generic`：其他普通单元或旧文件中没有语义标签的单元。

## 7. 气动标签

每个单元保存：

```cpp
ElementRole m_Role;
int m_WireId;
int m_AeroProfileId;
```

`m_AeroProfileId < 0` 表示不施加气动力。是否参与气动计算只由 `m_AeroProfileId` 判断，不直接由 `ElementRole` 判断。

| 单元 | Role | WireId | AeroProfileId |
|---|---|---:|---:|
| 子导线及两端过渡 | Conductor | 0..N-1 | 0..N-1 |
| 耐张联板、稳定梁 | TensionHardware | -1 | -1 |
| 相内间隔棒 | IntraPhaseSpacer | -1 | -1 |
| 相间间隔棒 | InterPhaseSpacer | -1 | -1 |

气动工况（分裂数、风速、覆冰厚度）属于荷载或分析步；`AeroProfileId` 只选择该工况内某根子导线对应的参数列。

## 8. 集合和持久化

每根子导线继续生成独立节点集和气动单元集。气动单元集包含整根子导线的全部导线单元，包括端部过渡，不包含耐张硬件和间隔棒。

H5必须保存并恢复 `ElementRole`、`WireId` 和 `AeroProfileId`。旧H5或普通BDF没有标签时使用：

```text
Role = Generic
WireId = -1
AeroProfileId = -1
```

BDF主要用于文本检查和几何查看，不保存 `ElementRole`、`WireId` 和 `AeroProfileId`；完整可继续计算的模型语义以H5为准。

## 9. 后续多档扩展

中间耐张点应共享同一个挂点节点，但左右档分别拥有自己的端部分组节点和端部硬件。每一档仍按本规范保存局部 `wireId` 和气动参数索引；需要跨档区分时增加线路/相线标识，不复用节点 ID 表达业务身份。
