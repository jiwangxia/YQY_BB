# 验证算例文件

## Le2012_Example1_RightAngle.bdf

Le et al. (2012) Example 1 的直角梁动力学模型。该文件已使用程序的
`Input_Model` 导入器加载并完成分析克隆校验。

导入后，在“编辑分析步”中选择：

- `Newmark-β`：作为固定步长基准；
- `自适应 TSSBN`：使用右列的 TSSBN 参数。

文件中包含 0--50--0 的三角脉冲（周期 2 s）、总时长 10 s、初始步长
0.10 s，以及直角梁的材料、截面、约束和载荷。该时程已经实际完成
Newmark 求解。原论文对比的 30 s 无阻尼长时程在当前实体梁非线性路径末段
会发散；在该稳定性问题修复前，不把它作为已通过的 BDF 验证。

## Conductor_IceGalloping_AdaptiveTSSBN.h5

四分裂导线覆冰舞动的完整模型。它保留导线气动束、覆冰厚度、风荷载、
分析步和自适应 TSSBN 参数；导入后可直接运行。

此模型不提供等价 BDF：当前 BDF 导入格式没有气动束、覆冰舞动开关、风
方向/密度和自适应 TSSBN 参数的字段。将它写成 BDF 会导入一个表面相似、
但没有舞动气动力的模型，因此不能作为舞动验证。

生成时已完成 Newmark 与自适应 TSSBN 的同模型对比：最大位移分别为
0.136426 和 0.141210，相对差 3.506%，两者均成功收敛。
