# 自适应时间积分框架理论

## 1. 基本思想

自适应步长的目标不是让步长始终变小，而是在满足误差容限的前提下，根据当前解的变化自动调整时间步长：

- 误差较大时缩小步长；
- 误差较小时增大步长；
- 误差合格时接受当前结果；
- 误差超限时回滚并重新计算。

整体流程为：

```text
试算 → 误差估计 → 接受/拒绝 → 调整下一步步长
```

## 2. 固定步长与自适应步长

固定步长的流程是：

```text
给定 dt
  ↓
积分一步
  ↓
提交结果
  ↓
进入下一个时间点
```

自适应步长的流程是：

```text
给定尝试步长 dt
  ↓
积分并估计误差
  ↓
误差是否满足容差？
  ├─ 是：接受结果，计算 dt_next
  └─ 否：回滚状态，减小 dt，重新计算
```

非线性求解失败导致的缩步属于“收敛回退”；误差估计导致的缩步才是严格意义上的自适应误差控制。

## 3. 步长加倍误差估计

假设当前时间为 \(t_n\)，尝试步长为 \(h\)。

先用一个整步计算粗解：

\[
y_A = \operatorname{Solve}(t_n,y_n,h)
\]

然后恢复到原始状态，用两个半步计算细解：

\[
y_B = \operatorname{Solve}\left(t_n+\frac h2,
\operatorname{Solve}(t_n,y_n,\frac h2),\frac h2\right)
\]

整步解和两个半步解都对应同一个末时刻 \(t_n+h\)。

对于 \(p\) 阶方法，Richardson 误差估计为：

\[
e \approx \frac{\left\|y_B-y_A\right\|}{2^p-1}
\]

因此：

- Newmark 按二阶处理：

  \[
  e \approx \frac{\left\|y_B-y_A\right\|}{3}
  \]

- 经典 RK4 为四阶：

  \[
  e \approx \frac{\left\|y_B-y_A\right\|}{15}
  \]

通常将两个半步得到的细解 \(y_B\) 作为最终接受结果。

## 4. 误差归一化

不能只比较位移差的绝对值，而应按照容差进行归一化。以位移为例：

\[
e_u =
\frac{\left\|u_B-u_A\right\|}
{(2^p-1)\left(\operatorname{atol}_u+\operatorname{rtol}_u S_u\right)}
\]

其中：

- \(\operatorname{atol}\)：绝对容差；
- \(\operatorname{rtol}\)：相对容差；
- \(S_u\)：位移状态的特征尺度。

结构动力学中不同物理量的量纲不同，最好分开处理：

- 平动位移：m；
- 转角：rad；
- 平动速度：m/s；
- 角速度：rad/s。

不能把这些量直接用同一组容差混合到一个范数中。更合理的做法是先逐自由度归一化：

\[
e_i=\frac{|(y_B)_i-(y_A)_i|}
{(2^p-1)[\operatorname{atol}_i+\operatorname{rtol}_i\max(|(y_A)_i|,|(y_B)_i|)]}
\]

然后取所有受监控自由度中的最大值：

\[
e=\max_i e_i
\]

最大值准则不会让某一个自由度的较大误差被其他自由度的较小误差平均掉，但通常比 WRMS 更保守。

## 5. 接受与拒绝准则

将归一化误差与 1 比较：

\[
e\leq 1
\]

表示当前步满足容差，可以接受：

```text
提交细解 yB
t ← t + h
计算下一步步长
```

如果：

\[
e>1
\]

则拒绝当前步：

```text
恢复到 t_n 的状态
减小 h
从同一个 t_n 重新计算
```

拒绝步骤不能推进物理时间，否则会破坏时间积分的连续性。

## 6. 下一步步长控制

局部误差通常满足：

\[
e\propto h^{p+1}
\]

因此下一步的建议步长为：

\[
h_{\text{new}}=s\,h\,e^{-1/(p+1)}
\]

其中 \(s\) 是安全系数，通常取 \(0.8\sim0.95\)。

对于两种积分器：

- Newmark：

  \[
  h_{\text{new}}=s\,h\,e^{-1/3}
  \]

- RK4：

  \[
  h_{\text{new}}=s\,h\,e^{-1/5}
  \]

计算结果还需要受到步长上下限和增长/缩小比例限制：

\[
h_{\min}\leq h_{\text{new}}\leq h_{\max}
\]

当前控制器实际采用：

```text
单次最大增长：2 倍
误差控制最小倍率：0.2 倍
无可信误差的求解失败：0.5 倍
```

其中“误差控制最小倍率”和“求解失败倍率”是两个不同参数：前者限制公式给出的倍率，后者只在
Newton 不收敛或单步积分失败、无法得到可信误差时使用。最终步长还会限制在用户设置的
`minimumTimeStep` 和 `maximumTimeStep` 之间，防止步长突然跳变或越界。

## 7. 完整算法流程

```text
t = t0
h = 初始步长

while t < t_end:

    h = min(h, t_end - t)

    保存模型状态检查点

    用 h 计算整步结果 yA

    恢复检查点

    用 h/2 计算第一半步

    提交半步内部材料状态

    用 h/2 计算第二半步，得到 yB

    计算误差 e

    if e ≤ 1:
        接受 yB
        提交材料和节点状态
        t = t + h
        h = 根据公式计算下一步
        记录结果

    else:
        恢复检查点
        h = 减小
        重试当前时间步
```

## 8. 软件模块划分

### 8.1 积分器

负责“如何从 \(t_n\) 积分到 \(t_{n+1}\)”：

```cpp
SolveSingleStep(model, time, dt)
```

Newmark 和 RK4 各自实现单步积分，不负责误差控制。

### 8.2 误差估计器

负责比较整步结果与两个半步结果：

```cpp
EstimateStepDoublingError(...)
```

误差估计器只接收状态并返回误差，不修改模型。

### 8.3 步长控制器

负责根据归一化误差返回：

```cpp
accepted
nextTimeStep
```

步长控制器不执行积分，也不保存结构状态。

### 8.4 状态检查点

负责保存、恢复和丢弃模型状态：

```cpp
PushStateCheckpoint()
RestoreStateCheckpoint()
DiscardStateCheckpoint()
```

需要恢复的不只是节点位移，还包括：

- 速度；
- 加速度；
- 单元材料历史；
- 塑性或其他非线性内部变量；
- MPC 乘子；
- 电缆扭转等历史状态。

RK4 还存在两种不同的回滚范围：每个 RK 单步内部的阶段回滚，以及整步/两半步比较外层的
自适应检查点。这两层状态必须独立保存；否则第二个半步的内部备份会覆盖步初检查点，拒绝该步时
节点虽然回到步初，单元历史却可能停留在第一个半步。

## 9. 当前代码的对应关系

当前项目的模块关系为：

```text
SolverNewmark / SolverRungeKutta4
        ↓
TimeStepError
        ↓
TimeStepControl
        ↓
StateCheckpointGuard
        ↓
IAnalysisModel 状态检查点
```

其中：

- Newmark 使用 \(p=2\)，误差除以 3；
- RK4 使用 \(p=4\)，误差除以 15；
- 接受后提交两个半步得到的细解；
- 拒绝后恢复检查点并重新计算；
- 固定步长模式不进行误差估计；
- 位移误差采用位移容差；启用速度误差时，速度使用独立容差；
- 每次求解记录接受次数、拒绝次数以及实际接受步长范围。

## 10. 工程实现中的注意事项

步长加倍法要求解在当前时间区间内具有一定光滑性。以下情况可能导致误差估计失效或过于保守：

- 荷载在某一时刻突然施加；
- 接触、碰撞、间隙刚刚打开或闭合；
- 材料刚刚进入塑性；
- 约束状态发生切换；
- 非线性迭代没有充分收敛。

工程实现中应考虑：

- 在事件点强制限制步长；
- 对不同物理量使用独立容差；
- 记录接受步、拒绝步、最小步长和最大步长；
- 对整段位移时程、相位和能量进行验证，而不是只比较最大位移。

还要特别区分“误差限制”和“稳定性限制”。局部误差合格并不保证显式 RK4 对结构最高频率稳定，
因此 RK4 的 `maximumTimeStep` 还必须小于模型的显式稳定步长；刚性很高的导线、梁或接触模型
通常更适合隐式 Newmark。当前通用误差接口已经将位移与速度容差分开，但平动和转角仍共用
各自所属状态量的容差；含大转动的六自由度模型后续还应使用相对旋转而不是直接相减绝对旋转向量。

分析步编辑器中的 Newmark/RK 自适应参数会随模型写入 HDF5，旧模型没有该数据集时使用默认值。

### 10.1 一致的初始加速度

动力分析不能只继承静力位移并把初始加速度强制设为零。若动力荷载在 \(t=0\) 已经生效，应先求解：

\[
M(u_0)a_0=F_{\mathrm{ext}}(u_0,v_0,0)-F_{\mathrm{int}}(u_0)-F_{\mathrm{other\ inertia}}(u_0,v_0)
\]

有 MPC 时还需同时满足加速度级约束。Newmark 和 RK4 必须从同一组
\((u_0,v_0,a_0)\) 出发，否则启动阶段会出现不属于积分误差的偏差。

### 10.2 RK 阶段内力必须刷新

RK4 的四个阶段具有不同的试探位移和速度。每次计算阶段加速度前都必须按当前试探位移重新计算
单元内力，再组装质量和外载：

```text
设置阶段位移、速度
  → 刷新当前单元内力
  → 组装质量与其他惯性项
  → 组装当前外载
  → 求解阶段加速度
```

若只更新质量和外载、却沿用上一个状态留下的内力，RK4 和 Newmark 实际积分的右端项并不相同；
这种错误会随时间累积，并造成明显的扭转和舞动历程分叉。

### 10.3 自适应不必然更快

当前步长加倍法每次尝试需要一个整步和两个半步，理论上至少是三次单步积分。若自适应的最大步长
不大于固定步长，它不可能凭借减少步数获得加速；严格容差使平均步长更小时，耗时还会进一步增加。

因此性能比较应满足两个条件：

- 固定方案与自适应方案达到相近的时间积分精度；
- 自适应方案允许在平稳区间采用明显大于固定方案的步长。

步长加倍适合先建立可靠、通用的误差控制基线。若后续目标是显著提速，应为各积分器增加共享阶段的
嵌入式误差估计器，避免为误差估计重复完成三次积分，而不是删除接受/拒绝和状态回滚框架。

## 11. 总结

自适应时间积分的核心分工是：

> 积分器负责试算，误差估计器负责判断精度，步长控制器负责调整时间步长，状态检查点负责保证拒绝后能够无痕回滚。

只要这四部分相互解耦，Newmark、RK4 或其他积分器都可以复用同一套自适应框架。
