# Battini 2002 第 7.2 节：静力螺旋梁

生成、比较和绘图脚本已移除。下文保留模型、参考来源与历史数值结论；旧输出路径不保证仍存在，不能将历史记录作为当前验收结果。

来源：Jean-Marc Battini，*Co-rotational beam elements in instability problems*，KTH 博士论文，2002 年 1 月。
算例为第 7.2 节 “Example 2, helical beam”，正文第 119–120 页，对应所提供 PDF 第 135–136 页；
几何与载荷见图 7.3，自由端 Z 位移主响应见图 7.4。PDF 的 SHA256 记录在 `reference/metadata.json`，不随本目录分发原 PDF。

这是静力大转动问题，Pseudo-time 表示加载进度，不是动力学时间。

## 输入与复现范围

| 项目 | 论文及本输入 |
| --- | --- |
| 初始几何 | 梁长 `L=10`，沿全局 X 轴，根部六自由度固定 |
| 广义刚度 | `EA=GA=1e4`，`EI22=EI33=GJ=100` |
| 网格 | 60 个梁单元、61 个节点 |
| 载荷 | 自由端全局 Z 向力与绕 Z 轴空间力矩，成比例加载至 `Fz=30`、`Mz=120*pi` |
| 加载参数 | `lambda=伪时间/6`；伪时间 `0..6`，步长 `0.002` |
| Newton | 容差 `1e-8`，每步最多 80 次迭代 |
| 观察量 | 节点 61 的全局 Z 位移；初始 Z 坐标为 0 |

`HelicalBeam.bdf` 使用当前生产 CR3D Euler–Bernoulli 共旋梁。论文采用 60 个减缩积分的 Timoshenko t3dl 单元，
当前 CR3D 没有论文的剪切柔度。因此，本项复现图 7.4 的主物理解支，不声称采用相同的单元公式，
也不包含论文中不同转动参数化、漏做端矩转换时的全部对比曲线。

输入中的 `E=10000`、`nu=-0.5` 使 `G=10000`，配合 `A=1`、`Iy=Iz=J=0.01` 编码上述广义刚度乘积。
这是刚度参数的等效编码，不用于声明实物材料与截面；密度和质量惯量为读取格式需要的正值占位，静力求解不使用。
全局空间端矩与当前节点空间增量转动共轭；输入不额外施加转动向量坐标下的端矩转换。

## 显式验证入口

在含 `YQY.sln` 的仓库根目录执行：

```powershell
.\x64\Release\YQYTests.exe --verify-battini-helical-beam tmp/battini-helical-beam
```

省略输出目录时由程序选用默认验证目录。测试实现位于 `YQYTests/Statics/HelicalBeam`，
显式命令从本目录真实 BDF 读入并调用生产求解器，随后回读本次 HDF5 结果。
该项属于显式的论文完整路径验证，不加入默认短测试。

验收必须同时满足完整伪时间 `0..6`、3001 帧、节点数据完整且有限、固定根部保持约束，
以及全部 755 个参考点处自由端 Z 位移的最大绝对差不超过 `0.02`。
候选曲线在参考伪时间处作线性插值，RMS 差仅报告。
缺失输入、提前停止、缺帧、非有限结果或参考哈希不符均不算通过。
输出目录保存本次计算和比较报告，生成 HDF5、日志与曲线不得写回本输入目录。

## 图线参考及精度边界

`reference/figure7_4_tip_z.csv` 包含图 7.4 主响应实线的 755 个矢量顶点读数，列为
`pseudo_time,tip_uz_graphical`。这是从独立原 PDF 提取的图线，不是作者原始数值数据。

提取按锁定 PDF 第 136 页内容流的非空路径编号，选取实线路径 21–26。
图框的 PDF 坐标 `x=150.545..462.187` 对应位移 `-2..6`，`y=507.941..753.763` 对应伪时间 `0..6`。
路径选择经原图叠加核对，排除了未做转动转换的虚线分支；标定没有使用 YQY 结果调整。
参考曲线线宽为 `0.698` PDF 点，整线宽约对应 `0.018` 位移。
有限图线顶点采样、轴定位及伪时间读数还会产生误差，因此 `0.02` 仅用于图示级主响应验收，不是严格解误差界。
CSV 同时登记原 CRLF 字节和统一 LF 后的 SHA256；验证入口统一换行为 LF 后校验，避免 Git 换行策略造成误拒绝。

原提取过程校验了 PDF SHA256、755 点及 CSV 标准换行哈希；其他 PDF 版本必须重新标定，不能直接复用路径编号。
本目录保留输入、参考 CSV 和来源元数据；提取脚本已移除，不保存运行产物。
