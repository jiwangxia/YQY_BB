# 物理算例输入与参考

本目录只保留测试需要的模型、独立参考、验收参数与来源说明。C++ 算例位于 `YQYTests/Statics`、`Dynamics`，运行方法见 [测试工程说明](../README.md)，登记见 [cases.json](../cases.json)。

## 分类

| 目录 | 用途 |
| --- | --- |
| `Statics` | 桁架、悬臂梁、非线性弹簧与螺旋梁输入和参考 |
| `Dynamics` | 梁、索、振子、约束摆和单导线输入与参考 |
| `Support` | 仍被 C++ 显式测试使用的共享参数与参考 |
| `Pending` | 待定或历史算例的数据；是否执行以测试工程登记为准 |

生成模型、提取文献曲线、比较结果、绘图和批量运行的 Python 脚本及缓存均已移除，旧路径适配器和映射清单也已移除。JSON 不全是临时文件：例如平面梁的输入、参考及误差门直接由 C++ 读取，仍须保留。

独立闭式解、匹配半离散参考、文献原题、图线读数和跨模型比较须分别注明；图线误差门不等于精确解误差，派生模型不冒充原论文逐数值复现。

## 数据与结果

保留的模型参数、参考数值和验收门槛不因清理改变。候选结果、求解日志和图表写入独立输出目录；缺失输入、提前停止或仅完成求解不计为数值通过。

各子目录说明中的历史结果仅适用于当时版本；旧 `tmp`、`output`、归档文件和 Python 命令不再作为当前可运行入口。当前状态以 C++ 测试实际结果及登记清单为准，清理不改写历史失败结论。
