# 三维柔性共旋梁动力：直角框架派生题

生成、比较和绘图脚本已移除。下文保留模型、参考来源与历史数值结论；旧输出路径不保证仍存在，不能将历史记录作为当前验收结果。

本目录保存独立动力参考、模型输入和来源说明。模型是两根长10的默认CR梁，根全固定，在肘节点施加Z方向三角载荷。位移超过5 m、存在非共轴节点角速度及非零应变能，覆盖柔性空间运动。它由公开直角框架问题派生，**不是作者原网格、原HHT算法或原曲线逐点复现**，也没有把静力/初态矩阵当动力验收。

独立参考不调用生产库、不加载候选内力/矩阵，不实现Newmark；由局部弹性势能复步求导、线性节点速度物理质量和Euler陀螺项构造43维四元数ODE，使用SciPy DOP853。默认动力插值必须与Le的一致三次惯性插值区分。公式、真实输入和来源见input.json。

原固定步0.01/0.005/0.0025的v2和v3两组均严格FAIL；加速度细层归一误差0.020947>0.001。后续仅追加0.0003125/0.00015625/0.000078125三层，同参考/门/容差，完整时程全状态精度达到原门，数值趋势恢复约二阶，但首层1565次precision-limited接受违反执行门，因此严格结论仍FAIL，认证阶为空。不得将诊断数值阶替代严格通过。
