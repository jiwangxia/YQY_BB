# 导线舞动实现与验证报告

更新时间：2026-08-05

## 1. 目标与结论

本项目已完成导线全局风荷载、基于相对风的准定常气动荷载，以及在动力分析步中随节点运动实时更新气动力的基本链路。

已用同一单分裂导线模型完成两组实际结果验证：

| 工况 | 风速 | 覆冰 | 初始攻角 | 结果 |
| --- | ---: | ---: | ---: | --- |
| 原始工况 | 10 m/s | 12 mm | 45° | 响应衰减，最终为静态风偏，不发生持续舞动 |
| 候选工况 | 10 m/s | 18 mm | 112.5° | 出现持续横风振动，确认程序可产生导线舞动 |

因此，原始 45° 工况不舞动的首要原因不是气动参数没有装配，而是该攻角附近的气动阻尼为正。候选工况的气动阻尼为负，且实际时程已经出现持续大幅横风振动。

## 2. 荷载与求解架构

### 2.1 全局风荷载

风荷载与重力一样，在荷载装配阶段处理，而不应分散到不同求解算法中。风速方向使用全局三维向量 `Force_Wind::m_direction` 表示，不限制为 X、Y、Z 轴。

对于普通风偏阶段，基础风荷载为全局均布线荷载：

```text
q_w = 0.5 * rho * U^2 * D
f_w = q_w * e_w
```

其中 `e_w` 为全局风向单位向量。单元装配时通过空间均布线荷载转换为节点等效荷载，因此单元自身转角不会改变风在全局坐标中的方向。

实现位置：

- `YQY/DataStructure/Load/LoadAssembler.cpp` 的 `AssembleWind`
- `YQY/DataStructure/Load/Force_Wind.h`

### 2.2 舞动气动荷载

当且仅当动态分析步的 `m_EnableGalloping` 为真时，程序才计算气动荷载。每一动力迭代在试算位移、速度更新后，重新组装外荷载：

```text
SetTrialKinematics
    -> Assemble_AllLoads
        -> AssembleGalloping
            -> ComputeKinematics
            -> getCoefficients(Cl, Cd, Cm)
            -> ComputeLineLoad
            -> AddElementForce
```

实现位置：

- `YQY/DataStructure/AnalysisStep/AnalysisStep.cpp`
- `YQY/DataStructure/Load/LoadAssembler.cpp`
- `YQY/DataStructure/Load/AerodynamicLoadCalculator.cpp`

### 2.3 精确相对风与攻角表达式

以当前单元轴向 `e1` 为基准，先将全局风速投影到单元法平面：

```text
U_n = U - (U · e1) e1
e2 = normalize(U_n × e1)
e3 = normalize(U_n)
```

中点平动速度为 `v`，扭转角速度为 `omega`，导线半径为 `r` 时：

```text
u_2 = -v · e2 - r * omega
u_3 = |U_n| - v · e3
U_rel = u_2 e2 + u_3 e3
alpha_flow = atan2(-u_2, u_3)
alpha = alpha_0 + theta - alpha_flow
```

动压使用真实相对速度：

```text
p = 0.5 * rho * D * |U_rel|^2
f_a = p * (Cd * e_drag + Cl * e_lift)
m_a = p * D * Cm * e1
```

这避免了将 `(v + r*omega)/U` 小角度近似直接用于整个力值计算。

## 3. 与 TSSBN 的对比

TSSBN 中 `Element_Cable_CR::Get_Attack_Angle` 使用：

```text
alpha = alpha_0 + theta - (v + r*omega) / Uz
```

并在每个动力迭代中调用 `Get_Element_GollapingForce`，将 `Cl/Cd/Cm` 对应的单元气动力装配到全局向量。

本程序与 TSSBN 的共性是：气动参数都在动力迭代中随当前速度和扭转更新。

主要差异如下：

| 项目 | TSSBN | 当前程序 |
| --- | --- | --- |
| 攻角 | 小角度近似 | `atan2` 精确表达式 |
| 动压 | 固定 `Uz^2` | `|U_rel|^2` |
| 参数 | 多项式拟合，部分工况写死 | CSV 缓存，按分裂数/风速/覆冰选择 |
| 子导线 | 单元编号映射 | 单元气动标签与 `BundleAeroMapper` 映射 |
| 风向 | 原实现较固定 | 任意全局三维向量 |

注意：当前程序在舞动步中会同时装配基础风荷载和完整 `Cl/Cd/Cm` 气动力。由于 `Cd` 已包含阻力，二者是否应叠加必须在物理建模层面明确。当前实现保留基础风荷载，便于先验证风偏；后续建议提供“舞动步由完整气动力替代基础风荷载”的选项，以便做对照。

## 4. 气动数据与单元映射

### 4.1 数据工况

气动数据位于：

```text
YQY/Import/Aero_Data/Input_Data/
```

支持：

- 分裂数：1、4；
- 风速：10、12、14、18 m/s；
- 覆冰厚度：12、18、20、25、28 mm；
- 每个剖面：0° 至 360°、5° 间隔、73 个数据点。

CSV 中的缺失数据已按对称/反对称规律补齐；读取后程序统一令 360° 等于 0°。攻角会归一化到 `[0°, 360°)`，因此 357°、1000° 等输入均可正确查表和插值。

### 4.2 多分裂导线

每个单元有独立的：

- `m_AeroBundleCount`：所属分裂数；
- `m_AeroProfileId`：子导线气动剖面编号；
- `m_WireId`：子导线标识。

在运行时，`BundleAeroMapper` 结合单元轴向、模型竖直方向和全局风向计算该单元使用的气动剖面。气动参数文件在分析步开始时只加载一次，单元循环只进行内存查表，不会重复读文件。

## 6. 气动稳定性快速筛查

对当前准定常横向模型，Den Hartog 气动阻尼判据为：

```text
H(alpha) = Cd(alpha) + dCl(alpha) / d(alpha)
```

其中导数的自变量必须使用弧度。按照当前程序的力方向约定：

- `H > 0`：正气动阻尼，扰动衰减；
- `H < 0`：负气动阻尼，存在自激舞动候选；
- `H = 0`：气动临界攻角。

由于程序对 `Cl/Cd/Cm` 使用分段线性插值，在每个 5° 区间内 `dCl/d(alpha)` 为常数，`H` 为线性函数。因此临界零点可以直接解析求得，无需以 1° 或更小步长扫描。

已新增可复用分析器：

```text
YQY/DataStructure/Aerodynamics/GallopingStabilityAnalyzer.h
YQY/DataStructure/Aerodynamics/GallopingStabilityAnalyzer.cpp
```

计划的命令行入口：

```text
YQY.exe --verify-galloping-stability <模型或结果H5文件>
```

它会输出每个已加载气动工况、每个子导线剖面的 `H < 0` 攻角区间。

2026-08-05 已完成 Debug/x64 全量编译，并实际运行该命令验证：

```text
YQY.exe --verify-galloping-stability 导线模型_20260804_132245_675_case_002.h5
case bundle=1 wind=10 ice=12 profiles=1 negative_intervals=2
  profile=0 alpha_start=165 alpha_end=180 min_H=-1.26473
  profile=0 alpha_start=185 alpha_end=195 min_H=-1.26473
```

### 6.1 原始工况的筛查结果

对于单分裂、10 m/s、12 mm 覆冰的剖面 0：

- 45° 处 `Cl = 0.98197`、`Cd = 1.822`；
- 45° 左右两侧 `H` 分别约为 `1.450`、`0.777`，均为正；
- 负阻尼区为 165°～180°、185°～195°。

## 8. 自动临界搜索方案

### 8.1 两阶段流程

不应对全部风速、覆冰、分裂数、剖面和攻角逐个跑长时程。建议采用两阶段策略：

1. **气动预筛**：用 `H(alpha)` 精确找出所有负阻尼攻角区间；
2. **动力确认**：仅在候选区间内，以小初始扰动运行短时程，计算跨中或指定监测节点的振幅包络增长率。

### 8.2 动力判定

对于监测位移 `z(t)`，去除移动平均后的包络为 `A(t)`。在一个观察窗内拟合：

```text
ln(A(t)) = sigma * t + c
```

判定：

- `sigma > tolerance`：增长，失稳；
- `sigma < -tolerance`：衰减，稳定；
- `|sigma| <= tolerance`：临界或需延长时程。

### 8.3 临界攻角与临界风速

- **临界攻角**：在稳定与失稳攻角之间二分；
- **临界风速**：目前只有 10、12、14、18 m/s 的离散气动数据，严格结果应报告为“临界位于两个相邻离散风速之间”；
- 若未来采用风速连续插值模型，可在相邻风速间二分，得到连续临界风速。

真正的耦合临界值还受导线张力、质量、几何、扭转刚度和边界条件影响。`H < 0` 只负责快速排除明显稳定的工况，不能替代动力确认。

## 9. 后续实施建议

1. 将 `GallopingStabilityAnalyzer` 接入分析步编辑界面，在用户选择风速、覆冰和攻角后即时提示是否处于负阻尼区；
2. 增加“自动临界搜索”任务类型，支持选择监测节点、扰动大小、观察时间和包络判据；
3. 在舞动步增加基础风荷载策略：`仅基础风`、`基础风 + 气动`、`仅完整气动`，明确是否与 `Cd` 重复；
4. 当舞动步内不存在气动标记单元时，阻止求解并给出明确错误，避免零气动力的假计算；
5. 将自动扫描结果保存到 H5 或单独 CSV，便于工况比较和后处理。
