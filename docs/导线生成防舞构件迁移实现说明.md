# 导线生成、防舞构件迁移实现说明

本文档面向“把当前已经实现的导线生成程序迁移到另一个程序”的场景。相比上一份逻辑文档，本文件更关注代码组织、可复用结构、核心算法代码骨架，以及迁移时需要替换的工程接口。

当前工程中，导线相关能力主要包括：

- 相线生成
- 地线生成
- 分裂导线子导线偏移
- 悬链线离散
- 相内间隔棒
- 相间间隔棒
- 防重锤
- 节点/单元 ID 索引维护

## 1. 建议迁移后的模块划分

如果在另一个程序中重新实现，建议不要直接把 `Model.cpp` 整段搬过去，而是拆成几个相对独立的模块：

```text
LineModelTypes.h/.cpp
  基础数据结构：导线配置、地线配置、档、相线、子导线、间隔棒、防重锤

ConductorGenerator.h/.cpp
  纯几何生成：悬链线、分裂偏移、原始节点/原始单元

LineAssembler.h/.cpp
  业务装配：根据挂点和配置生成相线、地线、相内间隔棒

AntiGallopingDeviceBuilder.h/.cpp
  防舞构件：相间间隔棒、防重锤、截面中心节点复用

InterPhaseSpacerStrategy.h
  相间间隔棒默认布置策略

ModelAdapter.h
  适配层：把“创建节点/创建单元/找节点/材料属性”映射到新程序自己的模型接口
```

迁移时最重要的思路是：把“算法”从当前 `Model` 类中剥离出来，把 `AddNode`、`AddElement`、`FindNode`、`GetNextNodeId`、`PropertyManager` 这些工程相关接口改造成适配层。

## 2. 当前工程中的核心依赖

当前实现依赖以下工程对象：

| 当前对象 | 作用 | 迁移时如何替换 |
| --- | --- | --- |
| `Node` | 有限元节点，保存 ID 和坐标 | 替换成新程序节点类 |
| `ElementTruss` | 导线线身桁架单元 | 替换成新程序杆/索/桁架单元 |
| `ElementBeam` | 间隔棒、联板、相间棒梁单元 | 替换成新程序梁单元 |
| `ElementMass` | 防重锤质量单元 | 替换成新程序质量单元 |
| `Property` | 材料+截面属性 | 替换成新程序材料截面对象 |
| `PropertyManager` | 根据材料名和截面名获取属性 | 替换成材料截面工厂 |
| `PropertyMaterialManager` | 查材料密度 | 替换成材料库 |
| `NodeHangBase` | 挂点/绝缘串信息 | 替换成新程序挂点数据 |
| `Model` | 全局节点、单元、ID 容器 | 替换成 `ModelAdapter` |

建议新程序至少提供下面这些能力：

```cpp
struct IModelAdapter
```

上面是伪接口，实际可以按你的另一个程序改成 Qt、C++ STL、C#、Python 或其他形式。

### 4.2 悬链线模型

当前实现采用悬链线。核心变量含义：

- `L`：起止点水平距离
- `h`：高差
- `b = stress / gamma`
- `X0`：最低点相对起点的水平位置
- `ArcLength`：总弧长

核心代码骨架：

```cpp
class CatenaryModel
{
public:
    double L = 0.0;
    double h = 0.0;
    double arcLength = 0.0;
    double lx = 0.0;
    double ly = 0.0;
    double gamma = 0.0;
    double minStress = 0.0;
    double x1 = 0.0;
    double y1 = 0.0;
    double z1 = 0.0;
    double b = 0.0;
    double x0 = 0.0;

    CatenaryModel(const double p1[3], const double p2[3], double unitWeight, double stress)
        : gamma(unitWeight), minStress(stress), x1(p1[0]), y1(p1[1]), z1(p1[2])
    {
        double dx = p2[0] - p1[0];
        double dy = p2[1] - p1[1];
        double dz = p2[2] - p1[2];

        h = dz;
        L = std::sqrt(dx * dx + dy * dy);
        if (L > 1e-7)
        {
            lx = dx / L;
            ly = dy / L;
        }

        b = stress / unitWeight;
        double c = std::sinh(L / (2.0 * b));
        x0 = L / 2.0 - b * std::asinh(h / (2.0 * b * c));
        arcLength = b * (std::sinh((L - x0) / b) + std::sinh(x0 / b));
    }

    bool GetPoints(double s1, double s2, int n, std::vector<Conductor::RawNode>& nodes, std::vector<double>& stresses)
    {
        s1 = std::max(s1, 1e-4);
        s2 = std::max(s2, 1e-4);

        double effectiveLength = arcLength - s1 - s2;
        if (effectiveLength < 0.0)
        {
            return false;
        }

        nodes.resize(n + 1);
        stresses.resize(n + 1);

        double sinhX0 = std::sinh(x0 / b);
        double coshX0 = std::cosh(x0 / b);
        double ds = effectiveLength / n;

        for (int i = 0; i <= n; ++i)
        {
            double si = s1 + i * ds;
            double xi = x0 + b * std::asinh(si / b - sinhX0);
            double cx = std::cosh((xi - x0) / b);

            nodes[i] = {
                x1 + xi * lx,
                y1 + xi * ly,
                z1 + b * (cx - coshX0),
                0
            };
            stresses[i] = minStress * cx;
        }
        return true;
    }
};
```

### 4.3 分裂导线偏移

偏移的思想是：先生成一条中心悬链线，再在垂直于线路方向的局部截面中，按分裂数布置子导线。

```cpp
static void Offset(const Conductor::ConductorConfig& cfg, double dx, double dy, std::vector<Conductor::RawNode>& offsets)
{
    double horiz = std::sqrt(dx * dx + dy * dy);
    if (horiz < 1e-9)
    {
        offsets.push_back({0, 0, 0});
        return;
    }

    double vrx = dy / horiz;
    double vry = -dx / horiz;
    double vvz = 1.0;

    int nBundle = cfg.nBundle;
    if (nBundle != 1 && nBundle != 2 && nBundle != 4 && nBundle != 6 && nBundle != 8)
    {
        nBundle = 1;
    }

    double startAng = 0.0;
    double radius = 0.0;

    if (nBundle == 2)
    {
        if (cfg.connecttype == Conductor::ConnectionMode::Horizontal)
        {
            startAng = 0.0;
            radius = cfg.spacing / 2.0;
        }
        else
        {
            startAng = -Conductor::PI / 2.0;
            radius = cfg.spacing / 2.0;
        }
    }
    else if (nBundle == 4)
    {
        startAng = -Conductor::PI / 4.0;
        radius = cfg.spacing / (2.0 * std::sin(Conductor::PI / 4.0));
    }
    else if (nBundle == 6)
    {
        startAng = -Conductor::PI / 3.0;
        radius = cfg.spacing / (2.0 * std::sin(Conductor::PI / 6.0));
    }
    else if (nBundle == 8)
    {
        startAng = -3.0 * Conductor::PI / 8.0;
        radius = cfg.spacing / (2.0 * std::sin(Conductor::PI / 8.0));
    }

    if (nBundle == 1)
    {
        offsets.push_back({0.0, 0.0, 0.0});
        return;
    }

    for (int i = 0; i < nBundle; ++i)
    {
        double angle = startAng + 2.0 * Conductor::PI * i / nBundle;
        offsets.push_back({
            vrx * std::cos(angle) * radius,
            vry * std::cos(angle) * radius,
            vvz * std::sin(angle) * radius
        });
    }
}
```

### 4.4 创建导线束

```cpp
Conductor::BundleResult CreateBundle(
    const double start[3],
    const double end[3],
    double s1,
    double s2,
    const Conductor::ConductorConfig& cfg)
{
    Conductor::BundleResult result;

    CatenaryModel model(start, end, cfg.unitWeight, cfg.stress0);

    std::vector<Conductor::RawNode> centerNodes;
    std::vector<double> nodeStress;

    if (cfg.connecttype == Conductor::ConnectionMode::Parallel ||
        cfg.connecttype == Conductor::ConnectionMode::Horizontal ||
        cfg.connecttype == Conductor::ConnectionMode::Vertical)
    {
        model.GetPoints(s1, s2, cfg.segments, centerNodes, nodeStress);
    }
    else
    {
        model.GetPoints(cfg.insulatorL, cfg.insulatorL, cfg.segments, centerNodes, nodeStress);
    }

    std::vector<Conductor::RawNode> offsets;
    Offset(cfg, end[0] - start[0], end[1] - start[1], offsets);

    for (int wireId = 0; wireId < cfg.nBundle; ++wireId)
    {
        auto offset = offsets[wireId];

        result.wiresNode[wireId].push_back({
            start[0] + offset.x,
            start[1] + offset.y,
            start[2] + offset.z
        });

        for (int j = 0; j < static_cast<int>(centerNodes.size()); ++j)
        {
            auto node = centerNodes[j];
            node.x += offset.x;
            node.y += offset.y;
            node.z += offset.z;

            result.wiresNode[wireId].push_back(node);
            int curr = static_cast<int>(result.wiresNode[wireId].size());
            result.wiresElement[wireId].push_back({curr - 1, curr, nodeStress[j], j == 0 ? 3 : 1});
        }

        result.wiresNode[wireId].push_back({
            end[0] + offset.x,
            end[1] + offset.y,
            end[2] + offset.z
        });

        int last = static_cast<int>(result.wiresNode[wireId].size());
        result.wiresElement[wireId].push_back({last - 1, last, nodeStress.back(), 3});
    }

    return result;
}
```

```cpp
double ComputeEndDrop(int wireCount, double intervalMm, ConnectionType orientation)
{
    if (wireCount <= 1)
    {
        return 0.0;
    }

    double dist = intervalMm / 2000.0 * (1.0 + 1.0 / std::tan(PI / wireCount));

    if (wireCount == 2)

        if (orientation == ConnectionType::Horizontal)
```

### 5.4 单分裂导线落入全局模型

裸导线生成器返回的是局部 `RawNode` 和 `RawElement`，装配层需要把它们转换成全局节点和单元。

```cpp
bool BuildSingleConductor(
    SpanSinglePhaseLine& phaseLine,
    const Conductor::BundleResult& raw,
    int leftNodeId,
    int rightNodeId,
    std::shared_ptr<Property> property,
    IModelAdapter& model,
    std::string& error)
{
    auto sub = std::make_shared<SubConductor>();
    sub->id = 0;
    sub->nodeIds.push_back(leftNodeId);

    auto nodes = raw.wiresNode.begin()->second;
    if (!nodes.empty())
    {
        nodes.erase(nodes.begin());
        nodes.pop_back();
    }

    for (auto& rawNode : nodes)
    {
        int nodeId = model.NextNodeId();
        auto node = std::make_shared<Node>(nodeId, rawNode.x, rawNode.y, rawNode.z);
        if (!model.AddNode(node))
        {
            error = "添加导线节点失败";
            return false;
        }
        sub->nodeIds.push_back(nodeId);
    }

    sub->nodeIds.push_back(rightNodeId);
    sub->lineBodyNodeIds = sub->nodeIds;

    auto elements = raw.wiresElement.begin()->second;
    for (int i = 0; i < static_cast<int>(sub->nodeIds.size()) - 1; ++i)
    {
        int elemId = model.NextElementId();
        double stress0 = i < static_cast<int>(elements.size()) ? elements[i].stress0 : 0.0;

        if (!model.AddTrussElement(elemId, sub->nodeIds[i], sub->nodeIds[i + 1], stress0, property))
        {
            error = "添加导线单元失败";
            return false;
        }
        sub->elementIds.push_back(elemId);
    }

    sub->lineBodyElementIds = sub->elementIds;
    phaseLine.subConductors[0] = sub;
    return true;
}
```

### 5.5 多分裂导线落入全局模型

多分裂比单分裂多两件事：

1. 每根子导线都要建一套节点/单元。
2. 耐张塔侧要把子导线按组连接到分组中点和联板梁。

建议迁移时先实现简化版：

```cpp
bool BuildBundleConductors(
    SpanSinglePhaseLine& phaseLine,
    const Conductor::BundleResult& raw,
    std::shared_ptr<Property> property,
    IModelAdapter& model,
    std::string& error)
{
    for (const auto& [wireId, rawNodes] : raw.wiresNode)
    {
        auto sub = std::make_shared<SubConductor>();
        sub->id = wireId;

        for (const auto& rawNode : rawNodes)
        {
            int nodeId = model.NextNodeId();
            auto node = std::make_shared<Node>(nodeId, rawNode.x, rawNode.y, rawNode.z);
            if (!model.AddNode(node))
            {
                error = "添加分裂导线节点失败";
                return false;
            }
            sub->nodeIds.push_back(nodeId);
        }

        for (int i = 0; i < static_cast<int>(sub->nodeIds.size()) - 1; ++i)
        {
            double stress0 = raw.wiresElement.at(wireId)[i].stress0;
            int elemId = model.NextElementId();
            if (!model.AddTrussElement(elemId, sub->nodeIds[i], sub->nodeIds[i + 1], stress0, property))
            {
                error = "添加分裂导线单元失败";
                return false;
            }
            sub->elementIds.push_back(elemId);
        }

        sub->lineBodyNodeIds = sub->nodeIds;
        sub->lineBodyElementIds = sub->elementIds;
        phaseLine.subConductors[wireId] = sub;
    }

    return true;
}
```

如果新程序需要完全复现当前端部联板逻辑，再继续迁移 `ProcessSideTopology` 这一段：按 `count1/count2` 把子导线分成两组，生成分组中点、挂点到分组中点的梁单元、两组之间的稳定梁。

### 7.1 标准间隔棒距离

当前规则可直接迁移：

```cpp
std::vector<double> CalculateStandardSpacerDistances(double totalHorizontalLength)
{
    std::vector<double> result;

    const double firstSpan = 30.0;
    const double secondSpan = 50.0;
    const double maxNextSpan = 62.5;
    const double minAllowableSpan = 20.0;
    const double asymmetryOffset = 5.0;

    if (totalHorizontalLength <= firstSpan * 2.0)
    {
        if (totalHorizontalLength > minAllowableSpan)
        {
            result.push_back(totalHorizontalLength / 2.0);
        }
    }
    else if (totalHorizontalLength <= (firstSpan + secondSpan) * 2.0)
    {
        result.push_back(firstSpan);
        result.push_back(totalHorizontalLength - firstSpan - asymmetryOffset);
    }
    else
    {
        double left1 = firstSpan;
        double left2 = firstSpan + secondSpan;
        double right2 = totalHorizontalLength - (firstSpan + secondSpan);
        double right1 = totalHorizontalLength - firstSpan;

        result.push_back(left1);
        result.push_back(left2);

        double midStart = left2;
        double midEnd = right2;
        double midLength = midEnd - midStart;

        if (midLength > 0.0)
        {
            int midSegments = static_cast<int>(std::ceil(midLength / maxNextSpan));
            double midStep = midLength / midSegments;

            if (midStep >= minAllowableSpan)
            {
                for (int i = 1; i < midSegments; ++i)
                {
                    double d = midStart + i * midStep + asymmetryOffset;
                    if (right2 - d < minAllowableSpan) continue;
                    if (i == 1 && d - left2 < minAllowableSpan) continue;
                    result.push_back(d);
                }
            }
        }

        result.push_back(right2 + asymmetryOffset);
        result.push_back(right1);
        std::sort(result.begin(), result.end());
    }

    return result;
}
```

### 7.2 创建默认相内间隔棒

```cpp
bool CreateStandardSpacers(
    SpanSinglePhaseLine& line,
    std::shared_ptr<Property> property,
    IModelAdapter& model,
    std::string& error)
{
    auto cfg = line.config;
    if (!cfg || cfg->dividedCount <= 1)
    {
        return true;
    }

    auto leftNode = line.leftHangPoint->lineNode;
    auto rightNode = line.rightHangPoint->lineNode;

    double dx = rightNode->x - leftNode->x;
    double dy = rightNode->y - leftNode->y;
    double length = std::sqrt(dx * dx + dy * dy);

    std::vector<double> distances;
    distances.push_back(0.0);
    for (double d : CalculateStandardSpacerDistances(length))
    {
        if (d > 1.0 && d < length - 1.0)
        {
            distances.push_back(d);
        }
    }
    distances.push_back(length);

    for (double d : distances)
    {
        auto spacer = std::make_shared<InnerSpacer>();
        spacer->id = model.NextElementId();
        spacer->position = d;
        spacer->hasCenterNode = cfg->dividedCount > 2;

        if (!BuildSpacerGeometry(line, property, spacer, d, model, error))
        {
            return false;
        }
        line.innerSpacers[spacer->id] = spacer;
    }

    return true;
}
```

### 7.3 找到目标距离对应的子导线节点

相内间隔棒最关键的是“沿顺线方向投影找节点”：

```cpp
int FindNearestNodeOnSubConductor(
    const SubConductor& sub,
    const Node& leftBase,
    double ux,
    double uy,
    double targetDistance,
    double totalLength,
    IModelAdapter& model)
{
    int nodeIdx = 0;
    bool found = false;

    auto first = model.FindNode(sub.nodeIds.front());
    double d1 = first ? ((first->x - leftBase.x) * ux + (first->y - leftBase.y) * uy) : 0.0;

    for (int i = 0; i < static_cast<int>(sub.nodeIds.size()) - 1; ++i)
    {
        auto n2 = model.FindNode(sub.nodeIds[i + 1]);
        if (!n2) continue;

        double d2 = (n2->x - leftBase.x) * ux + (n2->y - leftBase.y) * uy;

        if (d1 <= targetDistance && d2 >= targetDistance)
        {
            double err1 = std::abs(targetDistance - d1);
            double err2 = std::abs(d2 - targetDistance);
            nodeIdx = err1 < err2 ? i : i + 1;
            found = true;
            break;
        }
        d1 = d2;
    }

    if (!found)
    {
        nodeIdx = targetDistance <= 0.0 ? 0 : static_cast<int>(sub.nodeIds.size()) - 1;
    }

    if (targetDistance > 0.0 && nodeIdx == 0 && sub.nodeIds.size() > 1)
    {
        nodeIdx = 1;
    }
    if (targetDistance < totalLength && nodeIdx == static_cast<int>(sub.nodeIds.size()) - 1 && sub.nodeIds.size() > 1)
    {
        nodeIdx = static_cast<int>(sub.nodeIds.size()) - 2;
    }

    return sub.nodeIds[std::clamp(nodeIdx, 0, static_cast<int>(sub.nodeIds.size()) - 1)];
}
```

### 7.4 生成相内间隔棒梁单元

```cpp
bool BuildSpacerGeometry(
    SpanSinglePhaseLine& line,
    std::shared_ptr<Property> property,
    std::shared_ptr<InnerSpacer> spacer,
    double horizontalDist,
    IModelAdapter& model,
    std::string& error)
{
    int nWires = static_cast<int>(line.subConductors.size());
    if (nWires <= 1)
    {
        return true;
    }

    auto leftBase = line.leftHangPoint->lineNode;
    auto rightBase = line.rightHangPoint->lineNode;

    double dx = rightBase->x - leftBase->x;
    double dy = rightBase->y - leftBase->y;
    double totalLength = std::sqrt(dx * dx + dy * dy);
    if (totalLength < 1e-3)
    {
        error = "两侧挂点水平距离过小，无法生成相内间隔棒";
        return false;
    }

    double ux = dx / totalLength;
    double uy = dy / totalLength;

    std::map<int, std::shared_ptr<Node>> wireNodes;
    double sx = 0.0;
    double sy = 0.0;
    double sz = 0.0;

    for (auto& [wireId, sub] : line.subConductors)
    {
        int nodeId = FindNearestNodeOnSubConductor(*sub, *leftBase, ux, uy, horizontalDist, totalLength, model);
        auto node = model.FindNode(nodeId);
        if (!node) continue;

        wireNodes[wireId] = node;
        spacer->nodeIds.push_back(nodeId);
        sx += node->x;
        sy += node->y;
        sz += node->z;
    }

    if (wireNodes.empty())
    {
        return true;
    }

    int centerNodeId = -1;
    if (spacer->hasCenterNode && wireNodes.size() != 2)
    {
        centerNodeId = model.NextNodeId();
        auto center = std::make_shared<Node>(
            centerNodeId,
            sx / wireNodes.size(),
            sy / wireNodes.size(),
            sz / wireNodes.size());

        if (!model.AddNode(center))
        {
            error = "添加相内间隔棒中心节点失败";
            return false;
        }

        spacer->centerNodeId = centerNodeId;
        spacer->nodeIds.push_back(centerNodeId);
    }

    std::vector<int> wireIds;
    for (auto& [wireId, _] : wireNodes)
    {
        wireIds.push_back(wireId);
    }

    int edgeCount = nWires == 2 ? 1 : nWires;
    for (int i = 0; i < edgeCount; ++i)
    {
        int a = wireIds[i];
        int b = wireIds[(i + 1) % wireIds.size()];

        int edgeId = model.NextElementId();
        if (!model.AddBeamElement(edgeId, wireNodes[a]->id, wireNodes[b]->id, property))
        {
            error = "添加相内间隔棒外框梁失败";
            return false;
        }
        spacer->elementIds.push_back(edgeId);

        if (centerNodeId != -1)
        {
            int starId = model.NextElementId();
            if (!model.AddBeamElement(starId, wireNodes[a]->id, centerNodeId, property))
            {
                error = "添加相内间隔棒星形梁失败";
                return false;
            }
            spacer->elementIds.push_back(starId);
        }
    }

    spacer->position = std::clamp(horizontalDist, 0.0, totalLength);
    return true;
}
```

### 8.2 获取截面中心节点

这是相间间隔棒和防重锤共用函数。

```cpp
std::shared_ptr<Node> GetCenterNode(
    SpanSinglePhaseLine& line,
    double ratio,
    AntiGallopingBase& device,
    std::shared_ptr<Property> innerProperty,
    IModelAdapter& model,
    std::string& error)
{
    int nWires = static_cast<int>(line.subConductors.size());
    if (nWires == 0)
    {
        error = "导线没有子导线数据";
        return nullptr;
    }

    if (nWires == 1)
    {
        auto sub = line.subConductors.begin()->second;
        int range = static_cast<int>(sub->nodeIds.size()) - 1;
        int idx = std::clamp(static_cast<int>(std::round(ratio * range)), 0, range);
        auto node = model.FindNode(sub->nodeIds[idx]);
        if (node)
        {
            device.nodeIds.push_back(node->id);
        }
        return node;
    }

    auto firstSub = line.subConductors.begin()->second;
    int range = static_cast<int>(firstSub->nodeIds.size()) - 1;
    int idx = std::clamp(static_cast<int>(std::round(ratio * range)), 0, range);

    std::map<int, std::shared_ptr<Node>> wireNodes;
    double sx = 0.0;
    double sy = 0.0;
    double sz = 0.0;

    for (auto& [wireId, sub] : line.subConductors)
    {
        int localIdx = std::clamp(idx, 0, static_cast<int>(sub->nodeIds.size()) - 1);
        auto node = model.FindNode(sub->nodeIds[localIdx]);
        if (!node) continue;

        wireNodes[wireId] = node;
        device.nodeIds.push_back(node->id);
        sx += node->x;
        sy += node->y;
        sz += node->z;
    }

    if (wireNodes.empty())
    {
        return nullptr;
    }

    int centerNodeId = model.NextNodeId();
    auto center = std::make_shared<Node>(
        centerNodeId,
        sx / wireNodes.size(),
        sy / wireNodes.size(),
        sz / wireNodes.size());

    if (!model.AddNode(center))
    {
        error = "创建截面中心节点失败";
        return nullptr;
    }

    device.nodeIds.push_back(centerNodeId);

    // 如果当前位置没有相内间隔棒，这里补建一个辅助相内连接，保证相间棒不是悬空连接。
    // 当前工程会同时生成外框梁和星形梁，并把这些梁也登记到 device.elementIds。

    return center;
}
```

完整复现时，还应在多分裂处补建外框梁和星形梁，逻辑可直接复用相内间隔棒的 `BuildSpacerGeometry`。

### 8.3 生成相间间隔棒梁串

```cpp
bool CreateInterPhaseSpacerElement(
    Span& span,
    InterPhaseSpacer& spacer,
    IModelAdapter& model,
    std::string& error)
{
    auto lineIt1 = span.phaseLines.find(spacer.lineTag1);
    auto lineIt2 = span.phaseLines.find(spacer.lineTag2);
    if (lineIt1 == span.phaseLines.end() || lineIt2 == span.phaseLines.end())
    {
        error = "相间间隔棒找不到目标相线";
        return false;
    }

    auto property = model.GetProperty(spacer.materialName, spacer.diameter / 1000.0);
    auto innerProperty1 = model.GetProperty(lineIt1->second->config->materialName, lineIt1->second->config->diameter / 1000.0);
    auto innerProperty2 = model.GetProperty(lineIt2->second->config->materialName, lineIt2->second->config->diameter / 1000.0);

    auto n1 = GetCenterNode(*lineIt1->second, spacer.position, spacer, innerProperty1, model, error);
    auto n2 = GetCenterNode(*lineIt2->second, spacer.position, spacer, innerProperty2, model, error);
    if (!n1 || !n2)
    {
        error = "相间间隔棒端部中心节点获取失败";
        return false;
    }

    double dx = n2->x - n1->x;
    double dy = n2->y - n1->y;
    double dz = n2->z - n1->z;
    double distance = std::sqrt(dx * dx + dy * dy + dz * dz);

    int segments = std::max(5, static_cast<int>(std::floor(distance / 2.0)));
    double maxSag = std::clamp(distance * 0.1, 0.2, 5.0);

    std::shared_ptr<Node> prev = n1;
    for (int i = 1; i <= segments; ++i)
    {
        std::shared_ptr<Node> next;
        if (i == segments)
        {
            next = n2;
        }
        else
        {
            double t = static_cast<double>(i) / segments;
            double sag = maxSag * 4.0 * t * (1.0 - t);

            int nodeId = model.NextNodeId();
            next = std::make_shared<Node>(
                nodeId,
                n1->x + t * dx,
                n1->y + t * dy,
                n1->z + t * dz - sag);

            if (!model.AddNode(next))
            {
                error = "添加相间间隔棒中间节点失败";
                return false;
            }
            spacer.nodeIds.push_back(nodeId);
        }

        int elemId = model.NextElementId();
        if (!model.AddBeamElement(elemId, prev->id, next->id, property))
        {
            error = "添加相间间隔棒梁单元失败";
            return false;
        }
        spacer.elementIds.push_back(elemId);
        prev = next;
    }

    return true;
}
```

## 9. 防重锤实现

防重锤本质是一个质量单元：

- 锚点：相线截面中心节点
- 显示点：锚点下方 `hangerLength`
- 单元：`ElementMass`

```cpp
bool AddWeightHammer(
    Span& span,
    const std::string& lineTag,
    const std::vector<double>& distances,
    double massKg,
    double hangerLength,
    IModelAdapter& model,
    std::string& error)
{
    if (massKg <= 0.0)
    {
        error = "防重锤质量必须大于 0";
        return false;
    }

    auto lineIt = span.phaseLines.find(lineTag);
    if (lineIt == span.phaseLines.end())
    {
        error = "目标相线不存在";
        return false;
    }

    auto line = lineIt->second;
    auto left = line->leftHangPoint->lineNode;
    auto right = line->rightHangPoint->lineNode;

    double dx = right->x - left->x;
    double dy = right->y - left->y;
    double totalLength = std::sqrt(dx * dx + dy * dy);
    if (totalLength < 1e-3)
    {
        error = "档距过短，无法定位防重锤";
        return false;
    }

    double ux = dx / totalLength;
    double uy = dy / totalLength;
    double actualHangerLength = hangerLength > 0.0 ? hangerLength : 0.3;

    auto innerProperty = model.GetProperty(line->config->materialName, line->config->diameter / 1000.0);
    std::vector<int> hammerNodeIds;
    std::vector<int> hammerElementIds;

    for (double rawDistance : distances)
    {
        double d = std::clamp(rawDistance, 0.0, totalLength);
        double ratio = d / totalLength;

        auto hammer = std::make_shared<WeightHammer>();
        hammer->lineTag = lineTag;
        hammer->massKg = massKg;
        hammer->hangerLength = actualHangerLength;

        auto anchor = GetCenterNode(*line, ratio, *hammer, innerProperty, model, error);
        if (!anchor)
        {
            return false;
        }

        int visualNodeId = model.NextNodeId();
        auto visualNode = std::make_shared<Node>(
            visualNodeId,
            anchor->x,
            anchor->y,
            anchor->z - actualHangerLength);

        if (!model.AddNode(visualNode))
        {
            error = "添加防重锤显示节点失败";
            return false;
        }

        int massElementId = model.NextElementId();
        if (!model.AddMassElement(massElementId, anchor->id, visualNodeId, massKg))
        {
            model.RemoveNode(visualNodeId);
            error = "添加防重锤质量单元失败";
            return false;
        }

        double anchorDist = (anchor->x - left->x) * ux + (anchor->y - left->y) * uy;

        hammer->id = massElementId;
        hammer->position = std::clamp(anchorDist, 0.0, totalLength);
        hammer->anchorNodeId = anchor->id;
        hammer->visualNodeId = visualNodeId;
        hammer->nodeIds.push_back(anchor->id);
        hammer->nodeIds.push_back(visualNodeId);
        hammer->elementIds.push_back(massElementId);

        span.antiGallopingDevices[hammer->id] = hammer;

        hammerNodeIds.insert(hammerNodeIds.end(), hammer->nodeIds.begin(), hammer->nodeIds.end());
        hammerElementIds.insert(hammerElementIds.end(), hammer->elementIds.begin(), hammer->elementIds.end());
    }

    // 当前工程会把防重锤节点/单元补充进子导线容器，方便拓扑范围查询。
    for (auto& [_, sub] : line->subConductors)
    {
        for (int nodeId : hammerNodeIds)
        {
            if (std::find(sub->nodeIds.begin(), sub->nodeIds.end(), nodeId) == sub->nodeIds.end())
            {
                sub->nodeIds.push_back(nodeId);
            }
        }
        for (int elemId : hammerElementIds)
        {
            if (std::find(sub->elementIds.begin(), sub->elementIds.end(), elemId) == sub->elementIds.end())
            {
                sub->elementIds.push_back(elemId);
            }
        }
    }

    return true;
}
```

## 11. 迁移时必须注意的点

### 11.1 单位统一

当前工程里混用了：

- 直径输入：mm
- 子导线间距：mm
- 结构坐标：m
- 初始张力：按当前公式处理
- 应力：Pa
- 密度：kg/m3
- 容重：N/m3

迁移时建议在入口统一转换，内部全部使用 m、N、Pa。

### 11.2 节点和单元 ID

当前工程强依赖全局 ID：

```cpp
GetNextNodeId()
GetNextElementId()
AddNode()
AddElement()
FindNode()
RemoveNode()
RemoveElement()
```

新程序必须提供等价能力，否则相内间隔棒、相间间隔棒、防重锤无法共享节点。

### 11.3 相间间隔棒依赖相内中心节点

相间间隔棒不是简单连接两根导线某个节点，而是连接两根相线的截面中心。

如果是单导线，中心就是导线节点。

如果是多分裂，中心可能来自：

1. 已有相内间隔棒中心节点；
2. 临时补建的中心节点；
3. 二分裂时新增的形心节点。

这是迁移中最容易遗漏的地方。

### 11.4 防重锤也依赖 `GetCenterNode`

防重锤锚点不要直接挂在某根子导线上，否则多分裂导线会偏心。应该和相间间隔棒一样，先取相线截面中心。

### 11.5 相内间隔棒不要随意插入导线节点

当前实现是复用已有导线节点，按目标距离吸附到最近离散节点。这样不会打断导线单元，也减少重新剖分复杂度。

### 11.6 当前工程里的测试重锤逻辑

当前 `AssembleSpans` 中有测试性质的逻辑：每根相线跨中自动加一个 50 kg、0.5 m 吊杆的防重锤。

迁移到正式程序时，建议改成配置驱动：

```text
是否安装防重锤
安装相线 lineTag
安装距离列表
质量
吊杆长度
```

不要默认所有相线都安装。

## 12. 建议迁移顺序

推荐按下面顺序迁移，每一步都能单独验证：

1. 先迁移 `ConductorGenerator`，输入两个点，输出单根悬链线节点。
2. 增加分裂偏移，验证二分裂、四分裂、六分裂、八分裂几何。
3. 接入新程序节点/单元模型，实现单分裂相线。
4. 实现多分裂相线，但先不做复杂联板。
5. 实现地线。
6. 实现相内间隔棒，只验证二分裂和四分裂。
7. 实现 `GetCenterNode`。
8. 实现相间间隔棒。
9. 实现防重锤。
10. 最后补充默认策略、重新布局、追加间隔棒、删除清理逻辑。

## 13. 最小验证用例

建议新程序准备一个最小测试：

```text
左挂点: (0, 0, 30)
右挂点: (500, 0, 32)
导线:
  lineTag = 1A
  分裂数 = 4
  子导线间距 = 450 mm
  直径 = 30 mm
  初始张力 = 20 kN
  材料密度 = 2700 kg/m3

验证:
  1. 生成 4 根子导线
  2. 每根子导线节点数一致
  3. 跨中节点存在
  4. 相内间隔棒能连接 4 个子导线节点并生成中心节点
  5. 相间间隔棒能连接两相的中心节点
  6. 防重锤能在中心节点下方生成质量单元
```

## 15. 总结

迁移时可以把当前实现理解成两部分：

第一部分是通用算法：悬链线、分裂偏移、按顺线距离找节点、相内/相间构件几何。这部分可以直接复用或少量改造。

第二部分是工程胶水：节点 ID、单元创建、材料属性、挂点查询、容器索引。这部分必须根据另一个程序重写适配层。

只要新程序提供“节点/单元/材料/挂点”的基础接口，就可以按本文档顺序把当前导线、相内间隔棒、相间间隔棒和防重锤完整迁移过去。
