# YQY_CAE 代码框架工作树设计

日期：2026-07-14

## 目标

基于当前工程真实目录，在对话中输出一份可直接复制的纯文本工作树，供后续绘制代码框架图使用。

## 展示方式

采用“物理目录 + 中文职责”的混合工作树：

- 以 `YQY_CAE` 为根节点；
- 一级节点对应当前工程的主要物理目录；
- 核心模块展开到子目录和关键类；
- 每个目录或关键类后附简短中文职责；
- 使用 `├─`、`└─` 和 `│` 表示层级关系。

## 展示范围

工作树包含：

- 程序入口与工程配置；
- GUI 界面；
- 模型导入与气动参数；
- 数据结构，包括节点、材料、截面、属性、单元、约束、荷载、分析步和总体结构；
- 静力与动力求解器及统一接口；
- 导线和防舞构件建模；
- 结果导出；
- 通用工具和日志；
- 测试模块。

工作树省略：

- `ThirdPartyLibrary` 第三方库内部文件；
- `.git`、`.vs`、`x64` 等版本控制、IDE 和编译产物；
- `ExportFile`、`ExportH5` 等运行结果文件；
- 临时文件和调试生成文件。

## 详细程度

- `DataStructure` 和 `Solver` 展开两层，突出有限元核心框架；
- `Import`、`Export`、`Conductor`、`Utility` 和 `GUI` 列出关键类；
- 对同一职责的一对 `.h/.cpp` 文件合并显示为一个类名；
- 不展开单个成员函数，避免工作树过长；
- 对当前尚未实现的弹簧单元不虚构目录或类。

## 完成标准

- 目录名和关键类名与当前仓库一致；
- 能清楚看出从界面/输入、模型数据、分析求解到结果输出的模块划分；
- 能突出材料、截面、单元和求解器等会议关注内容；
- 输出为单个代码块，复制后层级符号不会错位。
