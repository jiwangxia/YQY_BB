# 位移约束 TABULAR 时程设计

## 目标

在静力分析步中，让位移约束可以按独立的分段线性时程变化。该功能与材料本构无关，弹性模型也可以使用。

## 输入格式

普通约束仍为四字段：

```text
约束ID, 节点ID, 方向, 基础位移
```

约束时程使用独立关键字，并按约束 ID 关联：

```text
*CONSTRAINT_TABULAR, 约束ID, 数据点数量
时间1, 缩放系数1
时间2, 缩放系数2
...
```

实际施加位移为：

```text
基础位移 * 当前时程缩放系数
```

没有时程表时，保持原有行为：

```text
基础位移 * 当前分析步线性因子
```

## 边界

- 不修改荷载时程。
- 不新增全局 Amplitude 类。
- 不修改材料本构。
- 不修改 HDF5 输出结构。

## 测试

- 表格首端、末端和区间内插值。
- 表格外时间取端点值。
- 非递增时间被拒绝。
- 不存在的约束 ID 和重复绑定被拒绝。
- 普通四字段约束仍按原来的线性因子工作。
