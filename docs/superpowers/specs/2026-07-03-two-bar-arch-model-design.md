# 两杆浅拱弹塑性位移控制模型设计

## 目标

将 Abaqus 模型
`D:/DownLoad/two_bar_arch_elastoplastic_disp_control_h50.inp`
转换为当前程序可直接读取和计算的 BDF 风格模型。

## 模型映射

- 节点保持 Abaqus 坐标：
  - 节点 1：`(-1000, 0, 0)`
  - 节点 2：`(0, 50, 0)`
  - 节点 3：`(1000, 0, 0)`
- 单元保持两个 `T3D2`：
  - 单元 1：节点 1—2
  - 单元 2：节点 2—3
- 截面积：`100 mm²`
- 材料：
  - `E = 200000 MPa`
  - `ν = 0.3`
  - 初始屈服应力 `σy0 = 250 MPa`
  - 各向同性硬化模量 `H = (350-250)/0.01 = 10000 MPa`
  - 密度、热膨胀系数均设为 0

## 约束和时程

- 节点 1、3 的 X/Y/Z 全部固定。
- 节点 2 的 X、Z 固定。
- 节点 2 的 Y 向基础位移为 `-200 mm`。
- 使用独立关键字按约束编号绑定：

```text
*CONSTRAINT_TABULAR, 9, 2
0.0, 0.0
1.0, 1.0
```

因此节点 2 的 Y 位移在一个分析步内从 0 线性变化到 `-200 mm`。

## 分析步和输出

静力步采用：

```text
1, STATIC, 1.0, 0.001, 1e-8, 100
```

共 1000 个固定增量。开启 HDF5 输出，用节点 2 的 `U2` 和 `R2`
对照 Abaqus。当前阶段不新增 LE、PE、PEEQ 文本输出。

## 验证

1. 模型读取成功；
2. 完成 1000 个增量；
3. 节点 2 的最终 `U2 = -200 mm`；
4. HDF5 中节点 2 的 `R2` 不全为零，并形成完整位移—反力路径；
5. 不修改现有求解器、材料算法或荷载时程。
