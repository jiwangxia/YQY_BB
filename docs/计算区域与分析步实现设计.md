# 计算区域与分析步实现设计

## 1. 目标

YQY 使用一份 `StructureData` 保存完整模型。塔、导线以及其他结构的节点、单元和全局 ID 都保留在同一模型中；计算区域只描述参与求解的空间范围，不拆分成多份模型数据。

本阶段先完成 YQY 内部计算区域能力，THOP 输出接口在内部结构稳定后再适配。

## 2. 已确认的业务规则

1. 计算区域由节点集合、单元集合及模型拓扑关系生成，与分析步参数无关。
2. 候选区域只要共享节点、共享单元，或者不同单元引用同一个端点节点，就必须合并成一个最终计算区域。
3. 最终启用的计算区域之间不得共享任何参与求解的节点或单元，只有通过校验的区域才允许并行。
4. 塔仍是完整模型的一部分；不把塔单元加入计算区域即可使其只参与完整模型显示而不参与求解。
5. 单元加入区域时，其全部端点节点必须自动加入区域。
6. 分析步只选择已经存在的计算区域，不创建、不拆分计算区域。
7. 一个分析步可以选择一个或多个计算区域；同一分析步选择的独立区域可以并行求解。
8. 导入文件包含分析步时保留导入的分析步及区域绑定；没有分析步时创建一个内置默认分析步，并作用于全部启用计算区域。
9. 用户新增或修改分析步时，必须在分析步编辑界面选择目标计算区域。
10. 原来的“运行某个分析步”功能保留。运行时，控制器把该分析步拆成若干区域求解单元并汇总状态和结果。

## 3. 数据模型

### 3.1 ModelSet

`ModelSet` 是用户选择和导入数据的基础集合：

- 全局唯一 ID 和名称；
- 集合类型为节点或单元；
- 保存全局节点 ID 或单元 ID；
- 不复制节点和单元对象。

### 3.2 ComputeRegion

`ComputeRegion` 保存：

- 全局唯一 ID、名称和启用状态；
- 来源集合 ID；
- 最终节点 ID；
- 最终单元 ID。

区域构建时先展开来源集合，再补齐所有单元端点节点，最后对有交集的候选区域求连通分量并合并。

### 3.3 AnalysisStep

现有 `AnalysisStep` 增加目标区域范围：

- `AllEnabledRegions`：作用于全部启用区域；
- `SelectedRegions`：作用于显式选择的区域 ID 集合。

分析类型、总时间、步长、容差和最大迭代次数等原参数保持不变。

## 4. 默认行为

模型完成导入或创建后执行规范化：

1. 如果没有计算区域，创建一个包含当前全部单元及其端点节点的默认计算区域；这使小模型也统一通过计算区域求解。
   该区域标记为自动生成；用户第一次新建显式区域时自动移除它，避免显式导线区域与“整模型默认区域”合并后又把塔带入计算。
2. 如果没有分析步，创建一个使用当前默认求解参数的“默认分析步”，区域范围设置为 `AllEnabledRegions`。
3. 如果存在分析步但没有显式区域绑定，统一绑定到 `AllEnabledRegions`。

上述默认行为只补齐缺失数据，不增加额外计算区域，也不改变已有的显式配置。

## 5. 求解流程

运行一个分析步时：

1. 解析分析步的目标区域；
2. 校验目标区域存在、已启用且互不重叠；
3. 为每个区域建立独立运行模型或运行上下文；
4. 只保留区域单元、区域节点以及命中区域的约束和荷载；
5. 各区域使用同一分析步参数并行求解；
6. 通过全局节点和单元 ID 汇总区域结果；
7. 未参与计算的完整模型实体保持原始坐标显示。

多个分析步即使选择同一区域，也必须使用独立运行状态，不能并发修改界面模型中的节点求解变量。

## 6. 界面

### 6.1 计算区域管理

模型/分析界面增加计算区域入口，至少提供：

- 区域名称、启用状态、节点数、单元数和来源集合；
- 新增、编辑、删除；
- 从节点 ID、单元 ID 或已有集合指定范围；
- 自动补齐端点、自动合并重叠区域；
- 独立性和引用有效性校验。

### 6.2 分析步编辑

现有分析步编辑器增加：

- “全部启用计算区域”；
- “指定计算区域”；
- 指定模式下的区域多选列表。

分析步列表增加“计算区域”列。

### 6.3 求解监控

用户仍以分析步为算例提交任务；任务详情显示内部区域进度。并发设置的含义改为最大并行区域任务数。

## 7. 数据一致性

- 删除或合并区域后，更新所有分析步的区域 ID 引用。
- 区域来源集合或模型拓扑改变后必须重新构建并校验区域。
- 求解期间禁止修改集合、区域、节点/单元拓扑和编号。
- 区域约束和节点/单元荷载按目标 ID 过滤；重力、风荷载等全域型荷载在每个区域内只遍历该区域单元。

## 8. THOP 后续接口

THOP 后续至少输出完整节点、单元、属性、集合、计算区域以及分析步到区域的绑定。YQY 内部使用全局 ID 恢复引用；缺失计算区域或分析步时仍按本设计的默认规则补齐。

## 9. 验收条件

1. 只有一个小模型且无区域/分析步时，可自动生成默认区域和默认分析步并完成计算。
2. 多个不重叠区域可由同一分析步选择和运行。
3. 共享节点或单元的候选区域会自动合并，不能作为并行区域保留。
4. 分析步参数变化不会改变计算区域数量。
5. 新增分析步可选择一个或多个已有区域。
6. 未进入区域的塔等实体仍在完整模型中显示，且不进入区域矩阵组装。
7. 运行任务不会修改界面使用的原始 `StructureData` 求解状态。
