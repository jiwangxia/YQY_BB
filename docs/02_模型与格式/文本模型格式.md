# 文本模型格式

本文说明当前 `Input_Model` 读取的 YQY 文本模型，将原通用格式说明与 MPC 格式说明合并。`.bdf` 或 `.inp` 扩展名本身不表示文件兼容 Abaqus/Nastran；外部软件原始输入保存在参考资料目录，需要转换为本程序关键字及自由度规则后使用。

解析实现见 [Input_Model.cpp](../../YQY/Import/Input_Model.cpp)，关键字与类型映射见 [EnumKeyword.cpp](../../YQY/Utility/EnumKeyword.cpp)。扩展字段应同时核对这两个入口，不以旧文档中的示意代码作为完整解析器。

## 基本约定

- 数据块以 `*关键字, 参数...` 开始，数量必须是可解析的非负整数，并与后续数据行一致；负数、小数、文本或缺失数量会拒绝。数据可用空格、Tab 或逗号分隔。
- 空行及以 `**` 或 `//` 开头的注释由 `ReadLine` 跳过，允许注释前缩进。模型先定义材料、截面、节点或弹簧行为，再定义引用这些对象的单元、约束和荷载。
- 方向编号从 0 开始：`0/1/2` 为 X/Y/Z 平动，`3/4/5` 为 RX/RY/RZ 转动；不能直接照搬 Abaqus 的 1 起始编号。
- 节点、材料、截面及部分荷载沿用按读入顺序编号的兼容逻辑，部分单元和约束保留显式 ID。新模型采用连续编号，并检查引用对象实际存在；不能笼统认为所有对象都会保留或重编号。
- 使用一致的单位制；几何、密度、力、力矩和时间函数频率必须相互匹配。
- 实际数值字段必须完整解析且有限，拒绝非法文本、`NaN` 与无穷值，不能由默认零值冒充有效输入。各类方向、正值及引用约束仍须分别满足下述规则。

## 节点与材料

```text
*NODE, 数量
ID, X, Y, Z

*MATERIAL, 数量
ID, 弹性模量, 泊松比, 密度, 许用应力, 膨胀系数
```

节点三个坐标均须有限。材料行共六字段，即 `ID` 加五个物理参数，五个参数均须有限，
弹性模量大于零，密度非负。材料、截面和节点仍按既有读入顺序建立最终编号，不因数值校验而改成保留任意输入 ID。

## 截面

```text
*SECTION, 数量
ID, 面积
```

两字段表示圆截面，面积必须为正有限数并由此推算半径；三字段 `ID, 宽度, 高度` 表示矩形，宽度和高度均须为正有限数。截面一共支持 2/3/8/11/12 五种字段格式；显式截面兼容以下字段：

```text
ID, A, Iy, Iz, J, JrhoX, JrhoY, JrhoZ
ID, A, Iy, Iz, J, JrhoX, JrhoY, JrhoZ, FirstX, FirstY, FirstZ
ID, A, Iy, Iz, J, JrhoX, JrhoY, JrhoZ, FirstX, FirstY, FirstZ, Radius
```

`A/Iy/Iz/J` 必须为正有限数。旧八字段格式的三个质量惯量要求为正，扩展格式允许非负；质量一次矩必须有限，可选半径非负。显式惯量、质量一次矩和独立物理半径不能通过同面积圆截面的几何量替代。

## 单元

| 类型 | 数据行 | 说明 |
| --- | --- | --- |
| `T3D2` | `ID, Node1, Node2, MaterialID, SectionID` | 二节点桁架 |
| `CABLE` | `ID, Node1, Node2, MaterialID, SectionID` | 二节点索 |
| `CR3D` | `ID, Node1, Node2, MaterialID, SectionID, DirX, DirY, DirZ` | 共旋梁，方向向量确定截面局部方向 |
| `SPRING1` | `ID, Node, DOF, BehaviorID` | 固定方向对地弹簧 |
| `SPRING2` | `ID, Node1, DOF1, Node2, DOF2, BehaviorID` | 两节点固定自由度弹簧 |
| `SPRINGA` | `ID, Node1, Node2, BehaviorID` | 沿两节点当前连线作用的轴向弹簧 |

块头为 `*ELEMENT, 类型, 数量`。当前类型映射使用 `CR3D`；旧说明中的 `B31` 不是当前映射中的等价关键字。

弹簧行为必须先于单元定义：

```text
*SPRING, 行为ID, 数据点数量
力, 相对位移
```

数据按相对位移严格递增，字段次序为力在前、位移在后。`SPRING1/2` 的 DOF 支持 `0` 至 `5`，转动自由度按当前节点六自由度配置处理；旧“仅静力平动自由度”说明已不完整。`SPRINGA` 不指定 DOF，使用两端节点的三个平动分量。

## 约束及 MPC

普通规定约束：

```text
*CONSTRAINT, 数量
ID, NodeID, Direction, Value
```

普通约束方向为整数 `0` 至 `5`，约束值须有限，节点引用必须存在；不能将非法方向转换成默认方向。
时程约束另按 `CONSTRAINT_TABULAR` 校验数据点、时间次序和已存在的约束引用。

MPC 使用以下格式；方向签名按字符串读取，必须保留前导零：

```text
*MPC, 数量
MPC_ID, MasterNode, SlaveNode, SlaveDirection
```

| 方向签名 | 当前含义 |
| --- | --- |
| `0`、`1` 或 `2` | 一条定长关系，该平动方向作为消元从自由度 |
| `05` | Boungard 与 Wackerfuß 2024 式 45 的平面非线性剪力释放：全局 Z 转角相等，旋转梁轴上的相对位移为零 |
| `012` | 三条相对位置关系，参考偏置由初始节点坐标确定 |

`05` 接近 90° 转动时可在从节点 X/Y 平动之间切换内部消元主元，输入与存储签名仍保持 `05`。不能把任意由 `0` 至 `5` 拼接的字符串都当成已支持的约束类型。同一从自由度不能重复约束或与规定约束冲突。完整推导和动力投影见 [MPC 约束理论与实现](../03_求解理论/MPC约束理论与实现.md)。

## 荷载与时间函数

```text
*LOAD, FORCE_NODE, 数量
ID, NodeID, Direction, Value, StepID
ID, NodeID, Direction, Value, StepID, StartTime, EndTime
ID, NodeID, Direction, Value, StepID, StartTime, EndTime, FunctionType, Params...
```

节点力基本格式至少五个字段，旧文档中省略 `StepID` 的四字段示例不可直接使用。时间函数支持 `CONSTANT`、`SIN`、`COS`、`RAMP`、`EXPONENTIAL`、`TRIANGULAR`、`SQUARE`；参数次序分别为：

| 类型 | 扩展参数 |
| --- | --- |
| `CONSTANT` | 无 |
| `SIN` / `COS` | 幅值、频率、相位、偏置 |
| `RAMP` | 开始时刻、结束时刻 |
| `EXPONENTIAL` | 衰减参数 |
| `TRIANGULAR` | 周期 |
| `SQUARE` | 周期、占空比 |

时间窗口与函数参数必须通过 `LoadBase::ValidateTimeFunction`，未知类型或非有限数会失败。其它荷载格式为：

```text
*LOAD, FORCE_ELEMENT, 数量
ID, ElementID, Direction, Value

*LOAD, FORCE_GRAVITY, 数量
ID, Direction, Value, StepID

*LOAD, FORCE_WIND, 数量
ID, Direction, Value, StepID
```

`FORCE_WIND` 的基础文本块不代表完整的覆冰气动工况配置。气动表、剖面标签和完整风荷载参数还需结合 HDF5 模型、导线建模及气动接口处理，见 [气动数据与稳定性判据](../04_气动与舞动/气动数据与稳定性判据.md)。

节点力与单元力的方向为整数 `0` 至 `5`，重力与风的方向为整数 `0` 至 `2`。
荷载值、时间窗口和函数参数必须为有限数，节点或单元引用必须存在。明确填写的零重力或零风速按零写入，不替换成默认值。
时间函数再检查窗口、频率、周期、占空比等自身规则，字段缺失或非法文本不能按零值继续读取。

## 分析步及其它块

```text
*ANALYSIS_STEP, 数量
ID, Type, TotalTime, StepSize, Tolerance, MaxIterations
```

`Type` 为 `STATIC` 或 `DYNAMIC`；总时间必须有限且非负，步长和容差必须为正有限数，最大迭代次数必须为正整数。更完整的积分器、计算区域和输出配置由分析步及 HDF5 接口管理，不应随意增加本六字段格式。当前解析器另支持 `CONSTRAINT_TABULAR`、`STRESS`、`AERO_ELEMENT`，扩展模型请以对应读取函数及 [HDF5 文件格式](HDF5文件格式.md) 为准。

## 读取测试与验证层次

[导入回归输入](../../YQY/TestModels/Import)仅保留12份合并后的正常文件，
供 [读取](../../YQYTests/Import) 中按11类组织的25项GoogleTest共用。
材料与五种截面格式集中在基础定义文件，六类单元各保留一份；约束、载荷、分析步及综合读取分别合并。
测试调用生产读取器，逐项检查实际变量、对象类型、缺省值及实体引用。
这些检查不启动全部算例求解；力学关系、求解终点与论文参考比较由后续对应测试验收。

## 可导入的最小桁架示例

该模型约束了全部非轴向自由度，避免把刚度奇异的示意模型当作有效基准。采用米、牛顿、帕、秒单位制；大位移本构结果与线性值 `FL/EA` 可存在小量差异。

```text
*MATERIAL, 1
1, 2.0e11, 0.3, 7850, 0, 0
*SECTION, 1
1, 0.01
*NODE, 2
1, 0, 0, 0
2, 1, 0, 0
*ELEMENT, T3D2, 1
1, 1, 2, 1, 1
*CONSTRAINT, 5
1, 1, 0, 0
2, 1, 1, 0
3, 1, 2, 0
4, 2, 1, 0
5, 2, 2, 0
*LOAD, FORCE_NODE, 1
1, 2, 0, 2000, 1
*ANALYSIS_STEP, 1
1, STATIC, 1, 0.25, 1e-9, 30
```

模型归类及参考输入位置见 [算例目录](../../YQYTests/TestModels/README.md)。
