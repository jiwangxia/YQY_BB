# 导线建模与编号

本文合并悬链线推导、当前拓扑编号规范和早期防舞构件迁移设计。前四节描述当前 YQY；第 5 节单独保留外部迁移的设计意图与未实现范围，避免把伪接口和旧策略当成现行 API。

## 1. 输入、范围与职责

当前支持 1、2、4、6、8 分裂的单档导线，以及同一耐张段内的多档导线。多档输入坐标表示各塔位的导线束/分裂多边形中心：首末站为耐张端，中间站为 H 型悬垂端。

| 模块 | 当前职责 |
|---|---|
| `ConductorModule` | 收集界面参数，建立工况和调用建模器 |
| `PropertyLibrary` | 创建材料、截面及属性 |
| `Generator / CatenaryModel` | 悬链线几何、精确站位重排及子导线截面偏移 |
| `ConductorModelBuilder` | 全局节点/单元装配、端部、相内间隔棒、集合、编号及失败回滚 |
| `StructureData` | 持有模型节点、单元、属性、MPC、惯性和集合 |

内部几何使用 m，力使用 N，应力使用 Pa，体积密度使用 kg/m³。界面的 mm/kN 输入必须先换算；应力、张力、线重和容重不能混用。材料和截面通过 `Property` 传入建模器，不由纯几何生成器查询界面或全局材料库。

## 2. 悬链线与分裂截面的几何推导

### 2.1 坐标约定

左右挂点为 `P1=(x1,y1,z1)` 与 `P2=(x2,y2,z2)`。程序以全局 `Z` 轴为竖直方向，并在 `XY` 平面内计算水平档距：

```text
dx = x2 - x1
dy = y2 - y1
h  = z2 - z1
L  = sqrt(dx^2 + dy^2)
eH = (dx/L, dy/L, 0)
```

`L` 为水平档距，`h` 为挂点高差，`eH` 为左端指向右端的水平单位向量。`L` 过小时无法建立悬链线。

### 2.2 从模型属性得到悬链线物理量

GUI 输入的 `initialStress` 单位为 Pa；材料密度 `density` 单位为 kg/m^3；截面面积为 `A`，单位为 m^2。`ConductorModelBuilder` 先计算：

```text
H = initialStress * A        水平张力，单位 N
w = density * A * g          单位长度线重，单位 N/m
g = 9.81 m/s^2
a = H / w                    悬链线参数，单位 m
```

其中 `H` 和 `w` 分别传入 `Generator::CreateBundle()`。应力（Pa）和体积密度（kg/m^3）不能直接代入悬链线公式；必须通过截面面积转换为张力和线重。

### 2.3 悬链线方程

在局部水平坐标 `X` 中，令最低点为 `X=X0`，则导线曲线为：

```text
z(X) = a * cosh((X - X0) / a) + C
```

从最低点量起的弧长函数为：

```text
s(X) = a * sinh((X - X0) / a)
```

由边界条件 `z(0)=z1`、`z(L)=z2`，程序得到：

```text
X0 = L/2 - a * asinh( h / (2*a*sinh(L/(2*a))) )
C  = z1 - a * cosh(X0/a)
```

全弧长为：

```text
S = a * [sinh((L-X0)/a) + sinh(X0/a)]
```

这些量分别对应 `CatenaryModel` 中的 `X0`、`C` 与 `ArcLength`。

### 2.4 按弧长离散节点

左右端可预留过渡弧长 `sLeft`、`sRight`。有效离散弧长为：

```text
Se = S - sLeft - sRight
ds = Se / n
si = sLeft + i * ds,  i = 0, 1, ..., n
```

由弧长反解局部水平坐标：

```text
X = X0 + a * asinh(si/a - sinh(X0/a))
```

随后获得全局节点坐标：

```text
x = x1 + X * eH.x
y = y1 + X * eH.y
z = a * cosh((X-X0)/a) + C
```

因此程序按弧长均分，而不是按水平长度均分，导线单元的实际长度更均匀。

### 2.5 张力与有限元初应力

理论张力大小为：

```text
T(X) = H * cosh((X-X0)/a)
```

其中 `T(X)` 的单位是 N。有限元导线单元的 `m_InitStress` 保存的是应力，单位 Pa，因此生成单元时写入的是用户输入的 `initialStress`，而非 `T(X)`。几何计算使用张力 `H=initialStress*A`，二者不能混用。

### 2.6 分裂导线偏移

中心悬链线生成后，`Generator::Offset()` 叠加各子导线在截面内的偏移。2、4、6、8 分裂分别采用正多边形布置，圆周率使用 C++20 的 `std::numbers::pi`：

```text
theta_i = theta0 + 2*pi*i/nBundle
offset = radius * (eR*cos(theta_i) + eZ*sin(theta_i))
```

`eR` 为水平横向单位向量，`eZ` 为竖直单位向量。`theta0` 固定 `wireId` 的截面顺序；编号规则见第 3.1 节。

### 2.7 调用链

```text
ConductorModule（读取界面输入）
    -> PropertyLibrary（创建材料、截面和 Property）
    -> ConductorModelBuilder::BuildLine / BuildSpanConductor / BuildMultiSpanConductor
    -> H = initialStress * area，w = density * area * 9.81
    -> Generator::CreateBundle
    -> CatenaryModel::GetPoints
    -> AddNodes / AddElements
    -> StructureData
```

### 2.8 前提和限制

- 当前实现只生成静力初始几何；后续静力求解负责有限元模型平衡。
- 全局 `Z` 轴为竖直方向。
- 水平档距过小、张力非正、线重非正或端部扣除弧长超过总弧长时，几何生成失败。
- 同一导线束中的子导线共享材料、截面、初始应力和中心悬链线，分裂差异由截面偏移、端部拓扑和气动标签表达。

### 2.9 截面半径、顺序与整束旋转

以相邻子导线间距 $s$ 表示正多边形半径：

$$
r=\frac{s}{2\sin(\pi/n)},\qquad
\theta_i=\theta_0+\frac{2\pi i}{n}+\theta_{\mathrm{bundle}}.
$$

| 分裂数 $n$ | 默认起角 $\theta_0$ | 半径 |
|---:|---:|---:|
| 1 | 无截面偏移 | 0 |
| 2 | 0 | $s/2$ |
| 4 | $-\pi/4$ | $s/[2\sin(\pi/4)]$ |
| 6 | $-\pi/3$ | $s/[2\sin(\pi/6)]$ |
| 8 | $-3\pi/8$ | $s/[2\sin(\pi/8)]$ |

当前 `bundleRotationDegrees` 使用角度制，转换后叠加到起角；多分裂要求其绝对值小于 $180/n$ 度，单分裂要求为零。整束旋转改变几何偏移，不改变 `wireId` 的逻辑顺序。旧迁移稿的二分裂水平/垂直 `ConnectionMode` 是外部设计，不是当前参数接口。

截面横向基向量还与气动剖面使用相同的轴向规范：把线路水平轴的主分量取正。反向输入同一档挂点时，子导线的物理方位与 `wireId` 对应关系由此保持一致；它不改变悬链线从左端到右端的弧长定义。

`segments` 描述生成器的中心线离散参数；完整节点链还包含挂点及端部过渡。验算最终节点/单元数时应按实际拓扑计数，不能把 `segments` 直接当成最终导线单元数。无精确站位时按有效弧长均分；有精确站位时按第 4 节重新分配节点。

## 3. 当前拓扑、编号与气动标签契约

### 3.1 子导线截面顺序

子导线按局部截面多边形排序，`wireId` 从 0 开始。四分裂的 `wireId=0` 位于局部右下角，之后沿多边形依次编号。

耐张端部按 `wireId` 分组：

- 二分裂：`{0,1}` 为一组；
- 四分裂：`{0,1}`、`{2,3}`；
- 六分裂：`{0,1,2}`、`{3,4,5}`；
- 八分裂：`{0,1,2,3}`、`{4,5,6,7}`。

同一组内的子导线共享左右分组节点，但各自拥有独立的导线单元。

### 3.2 耐张端部连接

“汇集单挂点”形式下，每一侧包含：

1. 一个输入坐标对应的耐张挂点；
2. 一个或两个分组节点；
3. 挂点到各分组节点的联板单元；
4. 两个分组节点之间的横向稳定梁（只有两组时创建）。

"分组双挂点"形式下，两个分组节点分别连接至两个挂点；输入坐标仍是双挂点的中点。双挂点间距默认等于子导线间距，允许单独修改；两个挂点沿两个分组节点的连线方向自动布置。

"子导线独立挂点（直接端部）"形式用于不含耐张金具的简化导线模型。输入坐标仍为分裂多边形中心；每根子导线在左右端各保留一个独立节点，并直接作为约束挂点。此形式不创建公共挂点、分组节点、耐张联板或稳定梁，所有线身单元均为 `Conductor`，可施加对应子导线的气动参数。

端部连接如下：

```text
                           子导线0
                    ┌────────────────
左挂点 ─ 左组节点1 ─┤
   │       |        └────────────────
   │       |               子导线1
   │       |
   |   横向稳定梁
   │       |
   │       |               子导线2
   │       |       ┌────────────────
   └── 左组节点2 ───┤
                    └────────────────
                           子导线3
```

分组节点到每根子导线首个独立节点，以及末个独立节点到右分组节点的单元，均属于导线，不属于耐张硬件。

### 3.3 多档 H 型悬垂端

多档模型中，首末站继续采用第 3.2 节的耐张端部。每个中间输入坐标 `C` 是分裂多边形中心，不是约束节点。程序反向构造：

```text
J = C + dist * Z
P = J + L * Z

dist = s/2 * [1 + cot(pi/n)]   (n > 1)
dist = 0                       (n = 1)
```

其中 `s` 为相邻子导线间距，`n` 为分裂数，`L` 为用户输入的悬垂串长度。四分裂拓扑为：

```text
                       P  悬垂约束节点
                       ●
                       │  H 型悬垂串
                       ● J
                      ╱ ╲
              wire 1 ●   ● wire 2
                     │ C │
              wire 0 ●   ● wire 3
```

连接到 `J` 的顶部子导线为：

- 二分裂：`wire 0、1`；
- 四分裂：`wire 1、2`；
- 六分裂：`wire 2、3`；
- 八分裂：`wire 3、4`。

单分裂时 `C` 对应的导线节点同时作为 `J`，只生成 `J-P` 悬垂串。中间站的各子导线节点、`J`、`P` 和悬垂硬件只创建一次，左右相邻两档共享这些节点。

耐张联板复用用户选择的导线单元类型；两分组节点之间的稳定梁固定为 `CR3D`；`J` 到顶部子导线的两根悬垂联板以及 `J-P` 竖向悬垂串均固定为 `T3D2` 桁架，保证悬垂上部只带平动自由度。

### 3.4 节点统一编号

模型几何、耐张端部和间隔棒全部创建完成后统一重新编号，不依赖对象创建顺序。

每个分组的编号顺序为：

1. 左分组节点；
2. 组内各子导线的独立线身节点，按 `wireId`、左到右排列；
3. 右分组节点。

所有分组完成后依次编号：

1. 左耐张挂点；
2. 右耐张挂点；
3. 各中间悬垂点的汇集节点 `J` 和约束节点 `P`；
4. 相内间隔棒中心节点、内圈节点；
5. 相间间隔棒新增节点；
6. 其他未分类节点。

四分裂、每根三个位于分组节点之间的独立节点示例：

```text
第一组
左组节点       1
子导线0        2,3,4
子导线1        5,6,7
右组节点       8

第二组
左组节点       9
子导线2        10,11,12
子导线3        13,14,15
右组节点       16

耐张挂点       17,18
附件新增节点   19...
```

逻辑节点链为：

```text
wire 0: 1 -> 2 -> 3 -> 4 -> 8
wire 1: 1 -> 5 -> 6 -> 7 -> 8
wire 2: 9 -> 10 -> 11 -> 12 -> 16
wire 3: 9 -> 13 -> 14 -> 15 -> 16
```

共享分组节点只有一个全局 ID，不创建重合的重复节点。

多档情况下，每根子导线按耐张段从左到右连续编号，中间悬垂站的共享子导线节点在该节点链中只出现一次。

### 3.5 单元统一编号

单元在模型生成完成后按以下顺序重新编号：

1. 各子导线的全部导线单元，按 `wireId`、左到右排列；
2. 左侧耐张联板；
3. 左侧稳定梁；
4. 右侧耐张联板；
5. 右侧稳定梁；
6. 各中间悬垂点的顶部联板和悬垂串；
7. 相内间隔棒；
8. 相间间隔棒；
9. 其他未分类单元。

端部过渡单元包含在对应子导线的连续单元序列中。

### 3.6 单元用途

```cpp
enum class ElementRole
{
    Generic = 0,
    Conductor,
    TensionHardware,
    IntraPhaseSpacer,
    InterPhaseSpacer,
    SuspensionHardware
};
```

- `Conductor`：整根子导线，包括左右端部过渡单元；
- `TensionHardware`：耐张联板和横向稳定梁；
- `SuspensionHardware`：中间悬垂端的顶部联板和悬垂串；
- `IntraPhaseSpacer`：相内间隔棒的全部单元；
- `InterPhaseSpacer`：相间间隔棒及其附属单元；
- `Generic`：其他普通单元或旧文件中没有语义标签的单元。

#### 相内间隔棒形式

当前 `InnerSpacerStyle` 定义以下形式；各形式仍须满足分裂数限制：

1. `外框多边形`：只连接相邻子导线节点，形成外框；
2. `中心对角撑`：外框加各外点至截面中心节点的辐射撑杆；
3. `内圈小多边形`：外框加按默认 `0.5` 比例生成的内圈，并连接每个外点与其对应内点。
4. `刚性中心 MPC`：中心主节点经刚性偏置及索轴向扭转约束保持分裂截面，附加等效刚体惯性，至少三个子导线节点；
5. `交叉对角撑`：四分裂外框加两条对角线，不增加中心节点，只支持四分裂。

普通二分裂形式只生成一根横向间隔棒；刚性中心 MPC 和交叉对角撑不适用于二分裂。中心 MPC 的理论、质量等效和柔度限制见[MPC 约束理论与实现](../03_求解理论/MPC约束理论与实现.md)。

### 3.7 自动端部约束

创建静力分析步时，端部约束不再固定为 XYZ，而是按用户选择的导线单元类型固定对应自由度：

- `T3D2` 桁架：`X, Y, Z`；
- `CABLE` 索：`X, Y, Z, RX`（第 4 个索扭转自由度）；
- `CR3D` 共旋梁：`X, Y, Z, RX, RY, RZ`。

耐张联板即使使用 `CR3D`，也不改变导线端部的自动约束数；因此桁架和索模型的联板转角保持自由，分别表现为端部铰接。

多档模型除约束首末耐张挂点外，还约束全部中间悬垂串的上端节点 `P`；分裂多边形中心、子导线端节点和汇集节点 `J` 均不直接约束。首末耐张挂点的约束自由度由主导线单元类型决定；当前 H 型悬垂串采用 `T3D2`，因此 `P` 只约束三个平动自由度。

### 3.8 气动标签

每个单元保存：

```cpp
ElementRole m_Role;
int m_WireId;
int m_AeroProfileId;
```

`m_AeroProfileId < 0` 表示不施加气动力。是否参与气动计算只由 `m_AeroProfileId` 判断，不直接由 `ElementRole` 判断。

| 单元 | Role | WireId | AeroProfileId |
|---|---|---:|---:|
| 子导线及两端过渡 | Conductor | 0..N-1 | 0..N-1 |
| 耐张联板、稳定梁 | TensionHardware | -1 | -1 |
| 悬垂顶部联板、悬垂串 | SuspensionHardware | -1 | -1 |
| 相内间隔棒 | IntraPhaseSpacer | -1 | -1 |
| 相间间隔棒 | InterPhaseSpacer | -1 | -1 |

气动工况（分裂数、风速、覆冰厚度）属于荷载或分析步；`AeroProfileId` 只选择该工况内某根子导线对应的参数列。

### 3.9 集合和持久化

每根子导线继续生成独立节点集和气动单元集。多档模型按整个耐张段汇总同一 `wireId` 的全部档内导线。气动单元集包含整根子导线的全部导线单元，包括端部过渡，不包含耐张硬件、悬垂硬件和间隔棒。

H5必须保存并恢复 `ElementRole`、`WireId` 和 `AeroProfileId`。旧H5或普通BDF没有标签时使用：

```text
Role = Generic
WireId = -1
AeroProfileId = -1
```

BDF主要用于文本检查和几何查看，不保存 `ElementRole`、`WireId` 和 `AeroProfileId`；完整可继续计算的模型语义以H5为准。

当前多档范围是：同一耐张段、首末耐张、中间 H 型悬垂、各档共用同一套导线和相内间隔棒参数。V 型悬垂串、中间耐张分段以及逐档参数覆盖属于后续扩展。

## 4. 间隔棒站位与生成完整性

### 4.1 水平站位与节点匹配

`InnerSpacerConfig::position` 是距左端的水平距离，不是弧长。已生成导线上直接调用 `BuildInnerSpacer` 时，`FindNearestNodeOnSubConductor` 按顺线水平投影寻找最近节点；内部站位排除端点。这个接口本身不会重新划分线身，不能保证目标距离精确落点。

`BuildSpanConductor` 及多档生成入口会先收集用户指定位置和等距自动布置位置，经 `BuildLineWithSpacerPositions` 传入 `Generator::CreateBundle`。`PlaceRequiredNodes` 在生成阶段把这些位置作为锚点：

1. 保留内部节点和线身单元数量；
2. 给严格递增的目标水平位置分配互不重复的内部节点序号；
3. 在可行分配中最小化节点水平移动的平方和；
4. 锚点之间对原水平坐标作单调分段线性映射；
5. 重新代入悬链线求高度，不用直线插值代替悬链线。

当前最短水平间距约束为

$$
\ell_{\min}=\max\!\left(10^{-6},\,
\min\!\left(0.01,\frac{L}{10(N_{\mathrm{node}}-1)}\right)\right)\ {\rm m}.
$$

要求站位有限、严格位于档内、无重复/过近位置，且可分配内部节点数量足够。若不能满足有序分配和最短长度，建模器返回明确错误，应增加离散段数或调整间隔棒间距。

因此旧迁移稿“所有间隔棒吸附最近节点、无需预先处理站位”只适用于旧方案或直接追加接口。当前精确站位通过重排已有节点实现，不增加节点/单元，也不能笼统描述成插入新节点。

### 4.2 等距与内置次档距策略

等距策略在起止避让范围内按用户指定数量计算位置；这些位置进入精确站位路径。内置次档距策略由 `CalculateStandardInnerSpacerPositions` 计算，当前常数如下：

| 量 | 数值 |
|---|---:|
| 首次档距 | 30 m |
| 第二次档距 | 50 m |
| 中段最大目标次档距 | 62.5 m |
| 最小允许次档距 | 20 m |
| 非对称偏移 | 5 m |
| 两端标记偏移 | $\min(0.1,0.01L)$ m |

短档满足 $L\le60$ m 时，若 $L>20$ m，增加跨中位置；$60<L\le160$ m 时，增加 $30$ 和 $L-35$ m；长档以左右 $30$、$80$ m 附近位置及中段按最大次档距划分，再作非对称偏移。结果排序、去重并限制在档距内。

内置规则的端部 0.1 m 标记保留原有约 1 m 过渡及吸附语义，不与用户指定/等距站位一起强制重排。该规则是程序内置布置策略，不能直接视为通用设计规范或任意电压等级的强制标准。

### 4.3 ID、连接、集合与回滚

原始几何索引必须映射为全局节点和单元 ID，所有共享连接复用同一节点对象。相内间隔棒的节点、单元、MPC 和刚体惯性均须登记到结果对象；多档端部和中间悬垂节点只创建一次。生成失败时应按本次创建记录回滚，不能误删已有模型对象。

模型完成后统一编号，同时更新子导线索引、端部/附件引用、集合以及约束关系。只改节点容器键或只更新显示编号会破坏模型连接。完整可继续计算的语义保存为 H5；普通 BDF 不携带全部角色/气动标签。

### 4.4 每套间隔棒总质量与刚度属性

创建界面的“每套质量”默认 **7.5 kg**，可输入正值。它表示一套完整间隔棒的质量，不是每根杆件的质量。跨内间隔棒和多档中间悬垂端的间隔棒分别按每套标定，悬垂串和联板不计入该套质量。底层 `InnerSpacerConfig::totalMass=0` 保留旧版按材料密度与截面计算的行为；负值和非有限值拒绝生成。

对一套由相同截面杆件组成的间隔棒，以各杆件的实际三维初始长度 $L_i$ 分配总质量：

$$
L_\Sigma=\sum_i L_i,\qquad
\rho_\mathrm{eq}=\frac{m}{A L_\Sigma},\qquad
m_i=m\frac{L_i}{L_\Sigma},\qquad \sum_i m_i=m.
$$

例如边长 0.4 m 的四分裂外框，4 根杆总长 1.6 m；加入两条完整对角杆后，6 根杆总长约 2.73137 m。指定 7.5 kg 时，两种拓扑的总质量都为 7.5 kg，杆件按长度分配，不是每根平均分为 $m/6$。增加对角杆仍会改变结构刚度和质量的空间分布；固定总质量不代表两种拓扑的转动惯量或动力响应相同。

生成器为每套杆件复制独立材料、截面和 Property，以等效密度实现质量标定，不修改源属性或导线属性；$E$、$\nu$、$A$、$I_y$、$I_z$、$J$ 保持所选刚度参数。若截面已指定单位长度质量惯量或质量一次矩，其质量项与密度按同一比例缩放。刚性中心 MPC 则同比缩放集中质量及完整转动惯量矩阵。

等效密度是当前有限元拓扑的质量分配参数，不能解释为真实合金密度。质量矩阵及重力都采用标定后的质量。HDF5 保存生成后的材料、截面、属性和 MPC 惯性；梁/桁架 BDF 保存标定后的属性。现有 BDF 输出不支持 MPC/刚体惯性，刚性中心模型应保存为 HDF5。文件保存的是生成后的数值模型，不包含重新生成用的“固定每套质量”参数；回读后直接改变几何不会自动再次归一质量。

### 4.5 间隔棒材料与截面资料的来源

2026-10-13 用户提供既有 `*ANTIMATERIAL` 资料，程序材料库录入独立预设；补充产品选型功能后，将原名称 **FJZ-445/400** 明确为 **ZL102（参考）**，材料编号与全部物性保持原值。该项作为间隔棒的默认参考材料，不代表任何型号的厂家材料认证。下表按用户原始值录入，并非本程序从产品型号自行推算：

| 参数 | 数值 |
|---|---:|
| 弹性模量 $E$ | $7.0000\times10^{10}$ Pa |
| 泊松比 $\nu$ | 0.33 |
| 实物材料参考密度 | 2650 kg/m³ |
| 特定工艺及状态的抗拉强度参考下限，不能作为屈服或许用应力 | $1.4500\times10^8$ Pa |
| 热膨胀系数 | $2.1100\times10^{-5}$ /K |

公开资料的核对结果应分别使用，不能将不同型号的数据拼成一套实物参数：

- [恒威通 JZF4 产品表](https://cn.henvcon.com/products_details/141.html)：JZF4-45300、JZF4-45400 等产品主要尺寸 450 mm、整套质量 7.5 kg；不是所有四分裂产品的统一质量规定。
- [内蒙古电力科学研究院原始检测论文](https://html.rhhz.net/nmgdljs/20170611.htm)，第 2 节：被检 JZF4-45400 材质为 ZL102。仅说明文中具体实物的材料牌号，不能据此确认用户 FJZ-445/400 资料的全部常数。
- [McWade 厂家目录](https://mcwadeproductions.co.za/wp-content/uploads/2023/10/McWade-Powerlines-Catalogue-2021-2023-07-28.pdf)，印刷第 25 页：四分裂 856890-00 的尺寸 A 为 400 mm、质量 5.000 kg，适用导线尺寸 27.00 mm。说明 400 mm 方案不必然为 7.5 kg。

上述公开厂家资料没有给出可直接用于梁单元的杆件 $A,I_y,I_z,J$。装配间距不是杆件截面尺寸；总质量还包含线夹、紧固件及阻尼部件，不能用 $m/(\rho L_\Sigma)$ 同时宣称得到了真实截面和真实刚度。因此本次不新增缺乏依据的“厂家专用截面”，现有可选截面仅作为刚度输入，须依据图纸、实测或整套刚度试验标定。材料库中的“单导线对照圆截面”仍是导线对照参数，并未转称间隔棒厂家截面。

[原始专利 CN101409439A](https://patents.google.com/patent/CN101409439A/zh) 的实施例确有 7.5 kg、450 mm 方框加一条斜撑、假设直径 20 mm 的圆杆并调整等效密度的建模方法。直径 20 mm 对应 $A=314.159$ mm²；按实心圆几何可推导 $I_y=I_z=7853.982$ mm⁴、$J=15707.963$ mm⁴。但原文明确是桁架简化假设，其材料取 $E=200$ GPa、$\nu=0.3$，并没有标定实物梁的弯扭刚度；本程序不将这些值与用户材料拼接为 FJZ-445/400 的已确认实物属性。

### 4.6 产品质量预设与直接编辑

创建导线弹窗分为“基础与坐标”“覆冰与扭转”“间隔棒”三页。分裂数放在页签上方的公共栏，在任意页均可切换；只有 2、4、6、8 分裂导线显示“间隔棒”页，单导线隐藏该页。在间隔棒页切回单导线时自动返回基础页，已输入的质量、间距、材料、截面及手工型号保留，切回分裂导线后可继续使用。页签显隐不重新调整弹窗尺寸。

间隔棒页采用两栏布局：左侧“产品与尺寸”提供质量预设、产品型号、每套质量、分裂间距和参考材料；右侧“建模与布置”提供建模形式、单元类型、布置方式、指定数量和截面。两栏参数行对齐；顶部统一控制是否创建间隔棒并显示预计生成数量。取消创建时保留页签和全部参数行，只禁用相应输入，避免布局伸缩。

质量预设按公共栏的分裂数筛选；下拉项同时显示 kg、型号和相邻子导线中心距，避免仅凭质量区分产品。目录保存在 `PropertyLibrary::spacerPresets()`，每项保留厂家与来源链接。当前录入双分裂、四分裂、六分裂共 10 项；未取得可靠目录质量的八分裂只提供自定义。

选择预设时填入质量、型号、间距和参考材料。启用创建后，质量、间距、型号可直接编辑，不需要勾选自定义；编辑只改变对应参数，不反向选择其他产品，也不重置其余数值。修改质量或尺寸后，原型号作为参考显示。再次选择预设（包括重新点击同一项）恢复该预设参数。选择“自定义”保留当前全部参数供继续修改；切换分裂数排除不兼容的产品预设，仅当型号仍是该预设原型号时改为“自定义间隔棒”，用户手工输入的型号保持不变，质量和尺寸不被默认值覆盖。

间隔棒页分裂间距与基础页子导线间距双向同步，共用 `config.conductor.spacing`；它不是沿档距的间隔棒布置距离。六分裂 FJZ6-375 系列目录标注的 750 mm 是分裂圆直径，正六边形相邻中心距为 375 mm，预设输入为 0.375 m。

未公开确切合金牌号的产品明确使用“材料（参考）”，对应用户物性预设，并可另选材料。选产品不推算杆件截面，不改变截面或有限元建模形式；切换形式仍遵循第 4.4 节的整套质量归一规则。重载属性库保留用户已编辑的质量、间距与当前属性选择。

2026-10-13 的 Release 编译及 `SpacerMass*` 11 项回归通过，当前检查源码为 `YQYTests/Conductor/SpacerMassTest.cpp`。界面回归覆盖页签显隐、手工参数保留、窗口尺寸稳定和两栏输入框逐行对齐；深色、浅色及深色 150% 显示比例的 gallery 均通过，无导线弹窗滚动条。输出与截图保存在 `tmp/spacer-tab-20261013`。

## 5. 早期迁移设计与后续防舞构件

### 5.1 外部设计对象与当前模块映射

原《导线生成、防舞构件迁移实现说明》面向把另一套 `Model/FEM` 工程迁往新程序，包含 `FEM/LineConfig.h`、`NodeHangBase`、`PropertyManager`、`ElementMass` 等外部对象。原文的 `IModelAdapter`、`LineAssembler`、`AntiGallopingDeviceBuilder` 和策略类是伪代码草案，不能作为本仓库已有类或可直接编译的示例。

| 原建议 | 当前可对应的能力 | 仍需明确的边界 |
|---|---|---|
| `ConductorGenerator` | `Generator / CatenaryModel` 纯几何 | 单位统一、站位规则按当前实现 |
| `LineAssembler` | `ConductorModelBuilder` | 材料/截面由属性传入，GUI 参数在入口转换 |
| `ModelAdapter` | `StructureData` 的创建/查找和 ID 管理 | 外部迁移时可自行适配，当前没有同名接口 |
| 地线生成 | 单分裂导线几何/装配可复用 | 不代表自动具备整个旧工程的线路业务 |
| 相间间隔棒策略 | 当前保留 `InterPhaseSpacer` 角色语义 | 旧策略和通用多相构件创建接口未作为当前公开建模 API |
| `ElementMass` 防重锤 | 当前已有 `RigidBodyInertia` 集中质量/惯性机制 | 不存在原草案的同名质量单元和自动安装流程 |

为迁移保留的正确原则是：纯几何不依赖全局模型；装配层统一 ID 和共享节点；构件按配置创建；失败可回滚；模型保存必须覆盖拓扑、属性和载荷语义。

### 5.2 相间间隔棒的历史设计意图

旧方案在两相相同档距比例处取得截面中心，再以梁串连接两中心。多分裂截面中心可能来自已有相内间隔棒、临时补建中心或二分裂形心；单分裂中心即导线节点。共享中心的创建、复用和所有权需一致，删除某个附件时不能破坏其他附件。

旧示例为“220 kV 垂直排列”提出以下布置，仅作为历史策略示例：

| 水平档距 | 旧示例的相间位置 |
|---|---|
| $100<L\le400$ m | A–B 在 $1/3$，B–C 在 $2/3$ |
| $400<L\le500$ m | A–B 在 $1/4$ 与 $3/4$，B–C 在 $1/2$ |

该示例未提供设计标准来源或当前实现验收，不能据此生成工程强制规则。正式实现前应明确连接柔度、端部释放、构件质量、精确站位和多相索引。

### 5.3 防重锤与质量建模的历史设计意图

旧方案把防重锤锚在相线截面中心，显示点位于中心下方 `hangerLength`，由 `ElementMass` 表示质量。其有价值的要求是质量为正、锚点明确、附件索引可追踪；“每根相线跨中自动加 50 kg、0.5 m 吊杆”属于旧工程测试逻辑，不是当前默认行为。

显示点不自动代表实体吊杆刚度；等效集中质量也不自动表示摆动、连接释放或偏心惯性。当前 `RigidBodyInertia` 能保存集中惯性，但新增防重锤业务仍需明确质量矩阵、吊杆/连接模型、重力和 H5 持久化，不能只迁移显示几何。

### 5.4 单位、初始应力和离散建议的冲突处理

旧伪代码使用 `b = stress / gamma`，其中变量名可能分别表示张力/线重或应力/容重。当前程序明确使用 $a=H/w$，其中 $H=\sigma_0A$、$w=\rho Ag$。若面积一致，两种写法可等价，但只有明确单位后才可互换。

由直径 $d_{\mathrm{mm}}$ 和张力 $T_{\mathrm{kN}}$ 计算应力时，正确关系为

$$
d=d_{\mathrm{mm}}/1000,\quad
A=\pi d^2/4,\quad
\sigma_0=\frac{1000T_{\mathrm{kN}}}{A}
=\frac{4T_{\mathrm{kN}}10^9}{\pi d_{\mathrm{mm}}^2}.
$$

旧骨架把悬链线局部张力变化写入 `stresses[i]`；当前 YQY 的 `m_InitStress` 保存用户给定的初始应力，不能直接把张力 $T(X)$（N）写进去。理论张力随位置的变化与后续有限元静力平衡需要分别理解。

旧建议约每 5 m 划分一段、至少两段并调整为偶数，是迁移建议，当前 `segments` 由配置给出。旧挂点下沉修正与现行 H 型悬垂的中心坐标反向构造也不能同时叠加，否则会重复改变高程。当前几何和端部规则以第 2–3 节为准。
