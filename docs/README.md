## 维护约定

修改已有功能时更新对应专题，不再按每次修改新增一份报告。公式保留符号定义，验证记录保留模型、版本、参数、判据及失败或部分完成的条件；同一推导仅在主专题维护，其他文档通过链接引用。

测试实现集中于 `YQYTests`，按实体文件夹分类；生产 `main.cpp` 保留桌面与隔离求解入口，原验证和审计参数由 `YQYTests.exe` 运行。模型输入仍存放于 `YQYTests/TestModels` 或 `YQY/Import/ImportFile/Examples`；运行输出、截图及参考软件工作目录存放于正式输出目录。原始参考数据与本程序输出分别标明来源，不能直接将历史输出视为正确答案。历史命令和二进制哈希保留当时含义，当前运行规则见开发指南与测试索引。
