# 静力与动力算例验收方案

当前测试工程以物理算例为核心，分为静力与动力两类。输入、工况、算法配置及参考构成可复现的数值验收记录。
统一登记为 [cases.json](../../YQYTests/cases.json)，实际目录、运行命令及本轮结果见 [测试说明](../../YQYTests/README.md)。

## 组织

- `YQYTests/Statics/<Case>`：静力物理算例与定量比较。
- `YQYTests/Dynamics/<Case>`：动力物理算例；同一模型的不同算法共用输入和独立参考。
- `YQYTests/Support`：必要的定位、生产读模、真实求解及参考比较辅助。
- `YQYTests/Runner`：统一main和物理算例入口，不承担界面、读取或内部hook测试。
- `YQYTests/Pending`：未完成、历史、内部诊断源码；不参与默认编译和通过统计。

`YQYTests/TestModels`按相同静力／动力及物理算例名存放模型与参考，共享冻结算法计划放Support。
历史及暂不能定性的资料保留在Pending，生产 `YQY/Import` 和界面示例不在删除范围。

## 每例登记

| 字段 | 要求 |
| --- | --- |
| 物理问题 | 几何、材料、单元、网格、约束、载荷或初态、单位以及物理假设 |
| 参考 | 解析理论、独立数值方程、商业软件版本与模型，或文献题目及原数据／图线 |
| 算法 | 静力方法或动力积分器及具体模式，步长／自适应容差、阻尼及收敛参数 |
| 验收 | 实际终点、需比较的物理量、预先声明误差门及需要的时间／空间细化 |
| 范围 | 完整AnalysisStep流程、真实单元适配器或仅积分器方程必须写清 |
| 证据 | 当前程序／输入／参考标识、全时程或加载路径、误差及明确状态 |

同一物理问题的不同工况、算法及参数档不重复计作新算例。
例如一个算例、两个工况、三种算法各三档步长，仍为一个算例，展开18次运行。
通过状态按“算例＋工况＋算法”登记，不能由另一算法、另一个时窗或不同物理离散的结果替代。

## 数值判定

静力以参考提供的加载路径、变形、内力及反力为准；动力在真实物理时刻比较参考提供的状态，必要时核误差阶。
仅有位移图线就只验证位移，不宣称速度或加速度通过。质量、惯性、阻尼、材料或边界与商业软件不同的对照必须声明差异。
刚体制造运动、柔性空间轨迹和论文原离散是不同验收范围，不能互相替代。

固定步与自适应分别遵循原计划：自适应的合法LTE拒步不自动等于失败；声明零回退或零precision的验收仍须满足原门。
不完整、参考缺失或超差应明确记录。路径重组不得改变模型、参考、算法参数或既定门槛。

读取、异常输入、界面、存储及内部阶段调用检查从当前默认力学清单移除。
算例执行所需的生产读取和完整性保护继续保留，程序跑完或文件写出成功不能单独登记数值通过。

单次时间细化只说明相对细步的一致性，不是独立理论真值，也不单独证明时间收敛。
