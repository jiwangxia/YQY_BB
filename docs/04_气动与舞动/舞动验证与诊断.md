## 2. 风向、重复平均风与早期45°/115°工况

本节的早期表与后面的八端点表属于不同阶段，不混合用于同模型逐点差。原始结果未附完整版本哈希时，保留原范围，不能把旧描述中的“当前”解释为2026-10-09。
旧 TSSBN 使用 `X=导线轴、Y=竖直、Z=来流`。当前导线模块使用 `X=导线轴、Z=竖直`。为保持右手坐标系，旧坐标到当前坐标的正确映射为：

\[
X_{old}\rightarrow X_{new},\qquad
Y_{old}\rightarrow Z_{new},\qquad
Z_{old}\rightarrow -Y_{new}.
\]

因此，旧 TSSBN 隐含的 `+Z` 风对应当前程序的 **`-Y` 风**，不是原验证程序使用的 `+Y` 风。当前四分裂几何以 `right=X\times Z=-Y` 为剖面 0 参考方向，`BundleAeroMapper` 的实现与这个结论一致：`-Y` 来流时 0 号子导线映射剖面 0，`+Y` 来流时映射剖面 2。

程序已将新建风荷载和舞动验证的默认参考来流改为 `-Y`。同时发现并修正了另一处装配问题：舞动步过去先调用普通风压装配，再调用包含完整平均阻力、升力和力矩的舞动装配，导致平均风荷载重复施加。现在舞动风只走 `AssembleGalloping`。

在修正风向和重复荷载后，45°、14 m/s、25 mm、四分裂、共旋索单元的 Newmark 30 秒结果仍然衰减：

旧固定方向公式遗漏阻力方向旋转的 `CD` 项，以及12mm多项式与25mm CSV不相同的推导，已集中到模型理论篇，不在各次诊断中重复。上述风向和重复普通风压修正并未改变本组45°衰减的观察。

## 3. 固定气动列与八端点模型

气动参数的“列”和“行”现在按两个阶段处理：

1. `AnalysisStep` 完成初始状态设置后，根据物理子导线标签、分裂数、该分析步风向、初始单元轴线和模型上方向，建立一次 `elementId -> profileId` 映射。
2. 同一动力分析步内，该列映射保持不变。Newmark 或自适应 TSSBN 的时间步和 Newton 迭代只根据瞬时攻角选择该列中的角度行，不再重新判断迎风/背风列。
3. 不同分析步具有各自的绑定缓存，因此同一模型使用不同风向时会在相应分析步开始前重新绑定，不会覆盖导线永久保存的 `wireId`。

生产装配如果发现参与舞动的导线单元没有分析步级绑定，会直接报错，不再静默回退到运行时重映射。

### 拓扑和边界条件

- 档距：200 m；
- 四分裂导线；
- 导线单元：`CABLE` 共旋索单元；

## 4. 53节点单导线45°同模型消融（2026-09-28）

45° 是正式 TSSBN GUI 允许且确实传入索单元的初始攻角。它不是运动全过程的固定攻角：实际攻角还含扭转角、竖向速度和扭转速度。此前的 170° 基准采用隔离测试版、完整相对风与 YQY 气动 CSV；170°还超出正式 GUI 的 −90°～90° 输入范围，不能由那次基准推出正式程序在 45°下不舞动。

按正式参考的原有气动力**公式**，隔离测试版在 45°、100 s 算出了持续增长的竖向振动。仅补全相对来流和升阻力方向投影，仍用参考原生多项式、1.29 kg/m³ 空气密度及其余相同设置，竖向振幅便衰减。因而，**遗漏相对风偏转时阻力的竖向投影是本次 53 节点 45° 差异的主要可复现实验因素**。这里的参考时程来自修复重复装配后的隔离 CLI，不是正式 GUI 的实测时程；正式 GUI 源码还存在重复计入舞动力的路径，可能进一步放大响应，量化影响需另做 GUI 对照。

### 小速度导数和单线原生多项式

本次 53 节点映射模型以 TSSBN 的 **Y 为竖向**。正式版 `Wind_method/Element_Cable_CR.cpp` 中，该方向的攻角反馈和力为

```text
α = α0 + θ − (r·ω + v_y)/U
F_y = ½ρdU² C_L(α)
```

攻角为 45° 时，`AerodynamicData.cpp` 的单导线 12 mm 新月形覆冰多项式给出 `C_L≈0.940758`、`C_D≈1.757435`、`dC_L/dα≈−0.549322/rad`。忽略扭转耦合、只看竖向小速度，参考原式有 `∂F_y/∂v_y=−½ρdU·dC_L/dα≈+0.0850 N·s/m²`（ρ=1.29 kg/m³、d=23.9778 mm、U=10 m/s）。这个气动力增量与竖向速度同向，提供负气动阻尼。

完整相对风处理把阻力也沿瞬时来流方向投影。竖向一阶项变为 `∂F_y/∂v_y=−½ρdU·(C_D+dC_L/dα)`。同一参考多项式在 45° 给出 `C_D+dC_L/dα≈+1.2081`，因此该项与速度反向。相对风速模长及反正切攻角的精确化对零速度处的这个一阶导数没有额外项；符号翻转来自缺失的阻力方向投影。YQY 的 5° 间隔 CSV 在恰好 45° 是折点：左右两段的 `C_D+dC_L/dα` 分别约为 `+1.4504`、`+0.7773`，符号相同。此小扰动分析只解释竖向气动反馈方向；完整系统还受扭转耦合与非线性影响，所以用 100 s 时程作了核对。

## 5. 覆冰结构、外力与惯性回归（2026-09-28）

1. **覆冰结构参数进入建模流程。**导线界面现可指定裸线实际外径、月牙形冰厚/中心角/半角、是否计入偏心质量与重力矩，以及独立的扭转刚度 `GJ`。冰质量在悬链线找形之前加入导线材料的等效线质量；冰的三轴转动惯量和一次质量矩单独写入截面。`GJ` 只改弹性扭转常数，不改质量惯量。端部金具与悬垂件使用独立的裸线属性，避免被导线覆冰误加质量。气动曲线的“覆冰厚度”仍是系数表选择，两处冰厚应由用户设成一致。
2. **气动力与切线一致。**相对风按当前导线速度和扭转速度重算；阻力沿瞬时相对风，升力按局部偏转角投影。轴向来风而导线横向运动时仍有正确的横向阻力。六自由度索节点气动力矩的数值切线使用扰动后的单元轴。分裂导线反向建模时，四个物理子导线方位与气动剖面编号保持对应。
3. **偏心冰重力满足节点反序。**修复索单元两节点互换时偏心冰重力平动力反号的问题；外力及外切线由独立势能差分和节点反序回归核对。
4. **自适应 TSSBN 误差控制。**默认按每个自由度分别缩放并取最大值，避免其他节点的大静挠度掩盖局部误差；保留 `legacy-global` 仅用于旧算例复核。该修正通常增加接受步数和耗时，不能把旧/新步数或相位差都归因于气动模型。
5. **模型文件。**扩展 BDF 截面字段保存实际半径、独立截面惯性矩、质量转动惯量和一次质量矩，并兼容旧列数；HDF5 逐字段往返核对同组数据。
6. **极陡分裂档的方向防护。**子导线剖面按水平档距定方位，索扭转/偏心重力/气动力矩按三维规范轴定正向。两种正向在极陡档相反时，现于剖面绑定和动力装配前明确拒绝该单元，错误给出单元 ID 与弦向量；气动切线的正负位置差分也在并行计算前预检，避免悄悄输出错误曲线。
7. **偏心冰索的动力惯性。**在索单元已有的平移–扭转一致质量矩阵基础上，补入截面随平均扭角旋转产生的离心/速度耦合惯性力及解析速度、扭角切线；无偏心索仍走原路径。恒扭速离心力、节点反序、两类切线差分和瞬时动能功率已做独立回归。
8. **HDF5 舞动工况保存。**增加可选数据集保存风密度、是否启用气动力矩，以及 TSSBN 误差范数。旧文件没有这些数据集时仍按旧默认值读取；默认、自定义及旧文件往返均有回归。
9. **显式 RK4 的变质量识别。**四自由度索只要有非零偏心质量一次矩，其一致质量矩阵就随扭角变化。RK4 现把这种索标记为状态相关质量，各阶段重新装配与分解质量矩阵；无偏心、四自由度索仍可复用缓存。
10. **覆冰索的 GPU 批量回退。**当前 CUDA 索内核只接受 `density × polarMoment` 的扭转质量，不接受偏心一次矩。两条 GPU 索批量路径现比较 CPU/内核实际使用的扭转质量，并检查一次矩；无法等价表达的单元交给已有 CPU 剩余单元路径装配，防止大模型或低 GPU 阈值下静默丢失冰惯性。质量参数等价的普通索仍可走 GPU；含偏心覆冰索的大模型可能因此比原先的错误 GPU 快速路径慢。
11. **混合 4/6DOF 索的转动惯量。**六自由度节点的轴向转动惯量现在随当前弦轴变化，惯性力、速度切线和配置切线保持一致。`--verify-cable-axis-inertia` 的功率误差为 `2.49e−13 W`，两类切线差分误差约 `1.1e−11`，节点反序误差约 `1.36e−20`。偏心冰一次质量矩随弦轴变化的导数仍属后续边界。

### 当时版本的代码成本来源与数值差异

1. **步数。**参考 `C:/APP/VS/TSSBN/Wind_method/AnalysisStep.h` 的 sa-TSSBN 默认最大 dt 是 0.5 s。YQY GUI 的 `AdaptiveTssbnSettings.h` 也是 0.5 s，但 `LegacyRunner.cpp` 的命令行验证默认最大 dt 为 0.005 s，既有 200 s 比较明确设为 0.02 s。此前测试是验证入口的步长上限造成大量额外步，并非 GUI 默认 0.5 s 没有生效。
2. **气动切线。**参考 `AnalysisStep.cpp` / `Dynamic_Solver.h` 每轮更新气动力，却没有把气动导数装入 Newton 矩阵；YQY `SolverAdaptiveTSSBN.cpp` 默认每轮请求气动切线。`LoadAssembler.cpp` 对一个 8 自由度索单元每列做正、负扰动，约 16 次单元气动力计算；200 个索单元约 3,200 次/全局切线。关闭此切线的速度收益已由同上限对照验证。它影响 Newton 迭代路径，应单独复核长时精度和收敛。
3. **阻尼。**参考 `Element_Cable_CR.cpp` 在单元上构造分离平动、扭转的比例阻尼 `C=y1 M_xyz+y2 K_xyz+c1 M_theta+c2 K_theta`，直接进入稀疏有效切线。YQY `StructuralDamping.cpp` 构造选定模态的稠密低秩因子，`LinearSystemSolver.h` 采用 Woodbury，一轮要处理 `rank+1` 个右端和小稠密系统。这两个阻尼模型数值上不等价；参考文本输入未保存四项阻尼系数，不能从输入文件断言相同阻尼。
4. **自适应控制和收敛。**参考 `DynamicStep.cpp` 的接受步预测含前一轮误差比与 Newton 工作量因子；YQY `SolverAdaptiveTSSBN.cpp` 当前只按本轮 LTE 比例预测。参考 Newton 判断还采用相邻残差变化量或修正量；YQY 检验当前力平衡残差。直接复制参考停止条件虽可能更快，却可能放松平衡精度。YQY 隐式阶段在检查残差前先组装完整切线，收敛末轮也会多做一次组装，值得作为保持判据不变的优化点。
5. **默认数值参数。**参考 GUI `rho∞=0.8`、`eps_LTE=5e-4`，YQY GUI 默认 `rho∞=0`、相对误差 `1e-3`；YQY 舞动验证入口显式将相对误差设为 `5e-4`，仍默认 `rho∞=0`。因此 GUI 和验证入口均不能仅凭名称视为参考程序同设置。
6. **相同积分器并不保证相同物理轨迹。**既有同模型、同 0.005 s Newmark 隔离试验见 `YQY/TestModels/Galloping/CrossProgram/README.md`：正式参考气动密度 1.29 kg/m³、参考多项式系数下，30 s 中点气动增量的平动矢量差为 0.03796 m、扭角差为 0.86894 rad；临时统一密度、气动表与偏心质量后，分别降为 0.000517 m、0.004113 rad。这个证据属于隔离版参考程序与 Newmark 测试，不能当作正式自适应 TSSBN 已经匹配；但足以说明物理输入不统一时，单独复制 TSSBN 公式无法让两条轨迹重合。

以上关于逐列有限差分切线、收敛末轮组装与默认参数的描述属于当时源码状态，不是对当前所有分支的重新审计。分析/装配后来加入解析导数、参考分支和其他优化后，不能直接沿用这些单步成本作为当前性能结论。

## 10. 尚未验证的边界与判定要求

- 单分裂的“先降再升”是重力找形后施风激发的瞬态，不是舞动必经步骤。静风精确预平衡而又完全无扰动时，即便平衡点不稳定，精确方程也会停留在平衡解；用 1 mm 扰动是在检验稳定性，不能说它是无扰动起振。
- 四分裂本轮 100 s 的增长与步长细化一致，但目标 300 s 的两组试算均因时间上限中止，且 220–240 s 窗口已相差最多 `5.651%`；**尚未证明 300–1000 s 的极限环及步长收敛**。不能用单条粗步长平台曲线证明物理恒幅，后续应再细化步长与误差容限并检查相位、模态能量和间隔棒响应。
- 月牙形冰采用当前程序的余弦厚度分布；没有证明其形状、气动表、间隔棒质量与用户图中的试验完全相同。BDF/HDF5 往返验证的是结构字段保存一致性，不是外部实验幅值验证。
- 对局部竖直高差大于水平主方向位移的极陡分裂索段，若水平规范轴与三维规范轴反向，程序现明确报错，不再静默计算；**此类几何的舞动求解尚未实现**。极陡但两轴同向、非正交分裂布置和导入模型的截面朝向也尚未做物理校准。本轮等高 200 m 档不触发该防护。
- 六自由度节点的轴向转动惯量 `J` 已包含弦轴变化的惯性力和切线；**偏心冰一次质量矩**随弦轴变化的导数仍未补齐。一个 4 m 单元、端点横移 0.8 m 的早期诊断例中，未纳入项约占总惯性力 `1.3–2.1%`，这不是本轮 200 m 舞动算例的误差界。诊断脚本见 轴向惯性范围评估（历史脚本已移除）。

判定应同时查看各线后段窗口、增长率或周期净做功、完整时长、相位及能量。HDF5/BDF往返是字段一致性证据，气动角度/切线/势能/功率回归是局部实现证据；二者都不替代公开试验幅值和长期收敛。尚未完成的试验和被主动终止的CSV继续明确标为部分结果，不提升为通过记录。
